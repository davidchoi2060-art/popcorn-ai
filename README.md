## 기존 대표 사진 만드는 규칙 (api/pc_media.py 와 같게)

- 사진 1장, 1:1 정사각, 실사 느낌의 조립 완제PC, 앞쪽 3/4 각도, 밝은 단색 스튜디오 배경, 케이스가 화면을 채움, **글자·라벨 없음**.
- 케이스는 참고 사진 그대로: 모양·색·앞판·유리·팬 위치를 바꾸지 않음. 유리 없는 면에 내부를 그리지 않음(COOLMAX 버디는 유리창 없음).
- 쿨러는 구성에 있는 공랭/수랭 하나만. 참고 사진에 없는 RGB 를 지어내지 않음.
- 참고 순서: 케이스 → CPU 쿨러 → 그래픽카드 (products.csv 의 reference_files).
- 기존 생성 모델: gemini-3.1-flash-image, 결과 원본 1254×1254 PNG.

## 화면 표시·구분 (바뀌지 않음)

- 상품 대표 사진은 화면에 **「AI 조립 예시 이미지 · 실제 출고 외형과 다를 수 있음」** 문구와 함께 보임. 사진 안에는 글자를 넣지 않음.
- 부품 사진은 실제 제품 사진(몰·공급사 사진)이라 문구 없음. 부품 사진은 AI 로 새로 그리지 않음.

## 납품 방법 (사진 적용 계약)

결과는 **D:\WORK\popcorn-image-return\** 폴더에 두면 클로드가 받아서 검사 후 화면에 붙임(코드·DB·배포는 클로드가 함).

```
popcorn-image-return/
  products/{상품번호}.png      예) 130569.png   1:1, 1024×1024 이상(기존 1254×1254), PNG
  parts/mall-{몰번호}.png      예) mall-126066.png  투명 배경, 여백 자름, 긴 변 600 이상
  manifest.csv
```

manifest.csv 열: `file,kind(product|part),id,sha256,width,height,case_code,note`
- id 는 상품번호 또는 부품 몰 번호(=연결 ID). 상품은 case_code 에 실제 쓴 케이스 몰 번호.
- 납품 안 한 번호는 지금처럼 몰 사진이 계속 보임(빈칸 안 생김).

화면 쪽 적용: 클로드가 상품 사진은 `mockups/mvp4/assets/images/products/{번호}.webp`, 부품 사진은 `mockups/mvp4/assets/images/parts/mall-{몰번호}.webp` 로 줄여 넣고, 서버 승인 사진이 없을 때 몰 사진보다 먼저 쓰게 연결함.
