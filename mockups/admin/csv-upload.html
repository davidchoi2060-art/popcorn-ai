    상품 일괄 등록 ADM-CSV-010 연결 안 됨

    CSV를 올리면 상품 원본 자료에 그대로 보존되고, 검증을 통과한 것만 정본에 반영됩니다.

    이 화면으로는 아직 실제 적재가 되지 않습니다. 아래 단계는 흐름을 보여주는 시늉이고, 버튼을 눌러도 상품 데이터는 바뀌지 않습니다. 지금 적재는 서버에서 tools/catalog_import.py로만 실행합니다 — 적재 결과는 일괄 등록 이력에서 실데이터로 확인하십시오.
    올린 원본은 수정할 수 없습니다. 값을 고치려면 파일을 고쳐 다시 올리거나, 상품 검수에서 확정하십시오. 같은 상품(SKU)의 가격은 공급처별로 따로 관리됩니다.
    1. 파일 올리기

    여기에 파일을 끌어다 놓거나 클릭

    .csv (UTF-8) — 파일당 최대 64MB · 엑셀은 CSV로 저장해 올려주세요

    ——행

    같은 공급처의 양식은 한 번 매핑하면 다음부터 자동 적용됩니다.

    2. 컬럼 매핑 확인

    프리셋으로 자동 매칭된 결과입니다. 예외만 확인하면 됩니다.

    먼저 파일을 올려주세요.
