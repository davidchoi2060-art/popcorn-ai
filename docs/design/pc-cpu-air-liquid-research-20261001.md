## 제조사 근거와 해석 구분

AMD 공식 CPU 사양: 9600X·9700X는 고성능 공랭 권장, 7800X3D·9800X3D·9950X는 최적 성능을 위한 수랭 권장이다. 권장은 필수 제약과 다르다. 특히 현 제품군 7800X3D 3개와 9800X3D 7개가 모두 별도 공랭이므로, 권장 정보와 실제 구성 및 조립 검수 근거를 별도로 보관한다.

Noctua는 9800X3D와 NH-D15 G2 공랭의 호환 및 성능 분류를 제공한다. 이는 수랭만 사용 가능하다는 분류가 부정확하다는 근거이며, 팝콘PC에 등록된 다른 공랭 모델의 냉각 성능을 검증한 근거는 아니다.

Intel은 소켓과 기본 전력을 냉각 솔루션 선택의 기초로 설명한다. 실제 지속 부하를 평가할 때 터보 전력·전력 제한·사용 시간·케이스 통풍도 기록한다. 예를 들어 i7-12700은 기본 전력65W/최대 터보180W, 14600K는125W/181W, 270K Plus는125W/250W다. 기본 전력만 보고 모두 기본 쿨러로 처리하지 않는다.

표의 일반 공랭 우선/수랭 우선/라디에이터 크기 선택은 당사 기획 제안이다. 모든 CPU 모델에 대한 제조사 공식 냉각 방식 지정이나 실측 인증으로 표시하지 않는다. 이 조사에서 어떤 CPU도 수랭 필수로 확정하지 않았다.

## 관리자 검색과 검수 적용 방향

- 실제 방식 필터: 기본 공랭 / 별도 공랭 / 수랭. CPU 모델 검색과 함께 사용한다. 포함 여부, 실제 장착 방식, 제조사 권장은 독립 항목이다.
- 냉각 정책 필터: 공랭 우선 검토 / 고성능 공랭·수랭 비교 / 제조사 수랭 권장 / 수랭 우선 검토. 추천 가능 상태와 별개다.
- 공랭은 소켓·브래킷·쿨러 높이·RAM/팬 간섭·케이스 통풍을 확인한다.
- 수랭은 소켓·브래킷·라디에이터 장착 위치와 크기·팬 포함 두께·RAM/보드 간섭·호스 배치·펌프 전원을 확인한다. 360mm 지원 여부만으로 모든 장착 간섭을 통과시키지 않는다.
- 240/280/360mm 선택은 케이스와 실제 쿨러 모델의 부하/소음 자료를 대조한다. 수랭이라는 이름만으로 더 조용하거나 FPS가 높다고 보장하지 않는다.
- 검수 기록: CPU/쿨러/케이스 정확한 모델, BIOS 전력 설정, 주변 온도, 작업/테스트 종류와 지속 시간, 온도·클럭·소음·스로틀링, 검사자·검사일.
- 기존 BOM 자동 교체나 가격 변경 없이, 변경 견적→규격 및 부하 검토→고객 동의→실조립 확인 흐름을 유지한다.
