# PC 조립 호환성 — 부품 목록과 검증 관계 전수 (2026-08-10)

> 사용자 지시: *"PC를 조립하기 위해서 필요한 부품과 그 부품과 연관되어 호환성을 체크할
> 부품들의 목록을 먼저 분석해서 조사해봅시다."*
>
> 근거 셋을 합쳤다: ① **우리 DB 실측**(규칙·사양 채움률) ② **저쪽 운영 ADMIN 실측**
> (`popcornpc-field-usage-2026-08-10.md`) ③ **웹 조사**(업계 표준 검증 항목 — 출처는 맨 아래).
> 표에서 **[실측]** 은 숫자를 직접 잰 것, **[웹]** 은 조사로 얻은 것이다.

---

## 1. 조립에 필요한 부품

| # | 부품 | 필수 | 비고 |
|---|---|---|---|
| 1 | **CPU** | ✅ | |
| 2 | **메인보드(MB)** | ✅ | **모든 부품이 여기를 거친다 — 호환성의 허브** |
| 3 | **메모리(RAM)** | ✅ | |
| 4 | **저장장치(SSD/HDD)** | ✅ | 최소 1개 |
| 5 | **파워(POWER)** | ✅ | |
| 6 | **케이스(CASE)** | ✅ | |
| 7 | **CPU 쿨러** | 조건부 | CPU 기본 쿨러 동봉이면 생략 가능 |
| 8 | **그래픽카드(GPU)** | 조건부 | CPU 내장그래픽이 있으면 생략 가능 |
| 9 | 시스템 팬 · ODD · 확장카드 · OS | ❌ | 선택 |

**우리 엔진의 슬롯 8개** = CPU · MB · RAM · GPU · SSD · POWER · CASE · COOLER — 필수 구성과 일치한다.
다만 **7·8번의 「조건부」를 우리는 표현하지 못한다**(내장그래픽 CPU여도 GPU를 반드시 고른다).

---

## 2. 호환성 관계 전수 — **17쌍**

### 그룹 A. 메인보드 중심 (논리·전기) — 6쌍

| # | 쌍 | 비교하는 것 | 우리 상태 |
|---|---|---|---|
| A1 | **CPU ↔ MB** | 소켓 일치 | ✅ 규칙 있음 |
| A2 | **CPU ↔ MB** | **칩셋이 그 CPU 세대를 지원하는가** | ❌ **`chipset` 93.7% 보유 · 규칙 없음** [실측] |
| A3 | **CPU ↔ MB** | **BIOS 버전** — 같은 소켓·칩셋이어도 신형 CPU는 업데이트 필요 | ❌ 데이터 자체가 없음 [웹] |
| A4 | **RAM ↔ MB** | 메모리 규격(DDR4/DDR5) | ✅ 규칙 있음 |
| A5 | **RAM ↔ MB** | **슬롯 수 vs 모듈 개수** · 최대 용량 | ❌ 없음 (저쪽 `메모리 슬롯 수` 505건 보유) |
| A6 | **RAM ↔ MB** | **클럭 지원(XMP/EXPO)** — 미지원 시 다운클럭 | ❌ `clock_mhz` 96.1% 보유 · 보드측 값 없음 |
| A7 | **GPU ↔ MB** | **PCIe 슬롯 유무·세대** | ❌ **`pcie_gen` 82.8% 보유 · 규칙 없음** [실측] |
| A8 | **SSD/HDD ↔ MB** | **M.2 슬롯 유무·개수·규격** / **SATA 포트 수** | ❌ **`interface` 78.7% 보유 · 규칙 0개** [실측] |
| A9 | **MB ↔ CASE** | 폼팩터 수용 | ✅ 규칙 있음 |

> **A3(BIOS)는 우리 정체성에 직접 걸린다.** "조립 불가능한 PC는 우리에게선 안 나온다"인데,
> 소켓이 맞아도 **부팅이 안 되는** 조합이 존재한다. 실무에서 가장 흔한 사고다 [웹].

> **A8이 가장 큰 구멍이다.** SSD는 8슬롯 중 하나인데 **호환 규칙이 하나도 없다.**
> NVMe SSD를 M.2 슬롯 없는 보드와 묶어도 지금은 통과한다.
> 게다가 **M.2를 쓰면 SATA 포트가 죽는 보드가 흔하다**(레인 공유) [웹] — 이건 우리가
> 지금 구조로는 표현조차 못 한다.

### 그룹 B. 물리 공간 — 케이스 중심 4쌍

| # | 쌍 | 비교하는 것 | 우리 상태 |
|---|---|---|---|
| B1 | **GPU ↔ CASE** | 길이(mm) | ✅ 규칙 있음 |
| B2 | **GPU ↔ CASE** | **두께(슬롯 수)** · 높이 | ❌ 없음 (저쪽 `카드 크기` 311건) |
| B3 | **COOLER(공랭) ↔ CASE** | 쿨러 높이 | ✅ 규칙 있음 |
| B4 | **COOLER(수랭) ↔ CASE** | 라디에이터 열 수 | ✅ 규칙 있음 |
| B5 | **POWER ↔ CASE** | **규격(ATX/SFX)** · **길이** | ❌ 없음 (저쪽 `지원 파워 규격` 826건) |
| B6 | **저장장치 ↔ CASE** | **베이 수(3.5"/2.5")** | ❌ 없음 (저쪽 `SSD 전용 베이` 673건) |

> **B5는 조립이 물리적으로 불가능해지는 항목이다.** SFX 케이스에 ATX 파워는 안 들어간다 [웹].
> 저쪽은 이 값을 **826건** 갖고 있는데 우리는 적재하지 않았다.

### 그룹 C. 전력 — 파워 중심 3쌍

| # | 쌍 | 비교하는 것 | 우리 상태 |
|---|---|---|---|
| C1 | **POWER ↔ GPU** | 정격 용량 ≥ GPU 요구 전력 | ✅ 규칙 있음 |
| C2 | **POWER ↔ 전체** | **총 소비전력 = CPU + GPU + 나머지 + 여유 20~30%** | ❌ **지금은 GPU만 본다** [웹] |
| C3 | **POWER ↔ GPU** | **보조전원 커넥터**(8핀 / 12VHPWR·12V-2x6) | ❌ 저쪽도 3건뿐 — 외부 수집 필요 |
| C4 | **POWER ↔ CPU** | **EPS 12V 커넥터**(8핀, 고급 보드는 2개) | ❌ 저쪽도 3건뿐 |

> **C2는 데이터가 이미 다 있다.** `rated_watt` 96.2% · CPU `tdp_watt` 72.1% ·
> GPU `required_power_watt` 78.2% [실측]. **규칙만 추가하면 된다.**
> 지금은 고TDP CPU + 중급 GPU 조합에서 파워가 부족해도 통과한다.

> **C3은 2026년 현재 실질적 위험이다.** RTX 50 시리즈는 12V-2x6을 쓰고, 어댑터를 쓸 때
> **각 8핀이 파워 쪽에서 서로 다른 케이블이어야 한다**는 조건까지 붙는다 [웹].

### 그룹 D. 냉각·간섭 — 3쌍

| # | 쌍 | 비교하는 것 | 우리 상태 |
|---|---|---|---|
| D1 | **COOLER ↔ CPU** | 소켓 지원 | ✅ 규칙 있음 |
| D2 | **COOLER ↔ CPU** | 냉각 성능(TDP) ≥ CPU TDP | ✅ 규칙 있음 (단 `cooler_tdp` **22.4%**만 채움) |
| D3 | **COOLER(공랭) ↔ RAM** | **램 높이 간섭** — 방열판 램 + 대형 공랭 | ❌ 없음 [웹] |

> **D3은 PCPartPicker 조차 못 하는 항목이라고 스스로 밝힌다** [웹].
> DDR5 고방열판은 유효 여유를 **5~12mm** 깎고, 케이스의 「최대 쿨러 높이」는
> **램이 40mm 이하라는 가정** 위에 적혀 있다 [웹]. 우리가 여기를 잡으면 차별점이 된다.

### 그룹 E. 출력 — 1쌍

| # | 쌍 | 비교하는 것 | 우리 상태 |
|---|---|---|---|
| E1 | **GPU ↔ 모니터** | 포트 종류·버전(HDMI 2.1 / DP 2.1)이 목표 해상도·주사율을 내는가 | ❌ 없음 · 주변기기 사양이 전멸이라 불가 |

## 3. 요약 — 17쌍 중 우리가 검사하는 것은 **7쌍 · 규칙 9개**

| | 쌍 |
|---|---|
| ✅ **검사함 (7)** | CPU-MB(소켓) · RAM-MB(규격) · GPU-CASE(길이) · MB-CASE(폼팩터) · COOLER-CPU(소켓·TDP) · COOLER-CASE(높이·라디에이터) · POWER-GPU(용량) |
| ❌ **안 함 (10)** | CPU-MB(칩셋·BIOS) · RAM-MB(슬롯수·클럭) · **GPU-MB(PCIe)** · **SSD-MB(M.2/SATA)** · GPU-CASE(두께) · **POWER-CASE(규격)** · 저장장치-CASE(베이) · **POWER-전체(총전력)** · POWER-GPU/CPU(커넥터) · COOLER-RAM(간섭) |

## 4. 우선순위

> **⚠ 이 절은 한 번 고쳐 썼다.** 처음엔 「데이터가 이미 있는 것부터」로 줄을 세웠는데,
> 그건 **엑셀에 맞춰 스키마를 짰던 실수를 형태만 바꿔 반복하는 것**이다.
> 사용자 지적(2026-08-10): *"팝콘컴퓨터 상품정보에 자세한 사양이 없을 수 있습니다.
> 상품을 판매하기 위한 목적이었지 호환성을 맞추는 게 아니기 때문입니다.
> 지금 체계를 세우면 사람이 입력해서라도 채울 수 있습니다."*
>
> **표준은 「호환 보증에 무엇이 필요한가」로 정한다. 채우는 방법은 그다음 문제다.**
> 아래 순위는 **「무엇을 먼저 채울까」**이지 **「무엇을 표준에 넣을까」가 아니다** —
> 표준은 §2의 17쌍 전부다.

### 채움 순서 1: 데이터가 이미 있고 규칙만 없는 것 (오늘 가능)

| 항목 | 필요한 필드 | 보유 |
|---|---|---|
| **C2 총 전력 합산** | `rated_watt` · CPU `tdp_watt` · GPU `required_power_watt` | **96.2% / 72.1% / 78.2%** |
| **A2 칩셋-CPU 세대** | MB `chipset` | **93.7%** |
| **A7 GPU PCIe 세대** | GPU `pcie_gen` | **82.8%** |
| **A8 SSD 인터페이스** | SSD `interface` | **78.7%** (보드측 M.2 값은 없음) |

> 넷 다 **엔진 사양으로 등록돼 있는데 어떤 규칙도 쓰지 않는다** [실측].
> A8은 SSD 쪽만 있어 반쪽이다 — 보드의 M.2 슬롯 수를 채워야 완성된다.

### 채움 순서 2: 저쪽이 이미 갖고 있어 적재로 해결되는 것

| 항목 | 저쪽 보유 |
|---|---|
| **B5 파워 규격(ATX/SFX)** | `지원 파워 규격` **826건** |
| **A8 보드 M.2 슬롯** | `M.2` **452건** · `M.2 폼팩터` 268건 |
| **A5 램 슬롯 수** | `메모리 슬롯 수` **505건** |
| **B2 GPU 두께** | `카드 크기` **311건** |
| **B6 저장장치 베이** | `SSD 전용 베이` **673건** |

> **적재만 하면 된다.** 저쪽이 이미 갖고 있는데 우리가 안 가져온 것이다.
> 단 저쪽 필드명이 **두 벌**인 것에 주의: `지원 파워 규격`(826)과 `지원파워규격`(430)이
> 따로 있다 — 옮길 때 합쳐야 한다.

### 채움 순서 3: 아무도 안 갖고 있어 **사람이 만들어야** 하는 것

| 항목 | 왜 어려운가 |
|---|---|
| **A3 BIOS 지원 목록** | 제조사 CPU 지원 목록을 부품별로 들고 있어야 한다. 저쪽에도 없다 |
| **C3/C4 전원 커넥터** | 저쪽에 **3건**뿐 — 사실상 없다 |

> **"데이터가 없다"는 표준에서 빼는 이유가 아니다.** 이 둘이야말로 **우리가 만들어야 할
> 표준**이다 — 저쪽에 없는 이유는 그쪽이 **판매용 정보**를 모았기 때문이고, 우리는
> **조립 보증용 정보**를 모으는 것이라 목적이 다르다.
> 다만 **채우기 전까지는 "우리가 이건 검증하지 않는다"고 화면이 밝혀야 한다** —
> 검증했다고 말하지 않는 것과 검증한 척하는 것은 다르다.

### 채움 순서 4: 아무도 안 하고 있어 **차별점이 되는** 것

**D3 쿨러-램 간섭.** PCPartPicker 도 못 한다고 스스로 밝히는 항목이다 [웹].
필요한 값은 쿨러의 **램 방향 오버행**과 램 **모듈 높이(mm)** 인데 둘 다 없다.
저쪽은 쿨러 `장착 가능 크기`(58건) · 램 `방열판`(657건, 유무만)을 갖고 있다.

## 5. 지금 규칙의 결함 하나 — 함께 적는다

**`cooler_tdp` 채움률 22.4%** (308/1,374). 규칙 D2가 이 값을 쓰는데,
NULL 은 **불통과**로 판정된다(`_cmp` 계약). 즉 **쿨러의 77.6%가 TDP 규칙에서 자동 탈락**한다.
규칙이 있는 것과 규칙이 작동하는 것은 다르다 — 이 항목은 다나와에도 없어
사람 검수 또는 제조사 자료가 유일한 길이다(CLAUDE.md 기록).
