# 사전 생성 견적 격자 — 벤치마크와 초안

**파일 경로:** `docs/design/prebuilt-grid-benchmark-2026-09-07.md`

**상태: 제안. 확정 결정이 아니다** — 티어 경계·용도 목록·명칭은 전부 사장님 확정 대기.
**선행 문서:** `docs/design/category-4tier-handoff-2026-09-04.md` (분류 4단 인계 — 별건, 미정 4건은 그대로 보류) ·

## 0. 새 컨셉 한 줄

**LLM이 실시간으로 부품을 조합하지 않는다.** 격자(티어 × 용도 × 플랫폼)의 칸마다
견적을 **미리 생성해 두고 주기 갱신**하며, LLM은 고객 질문을 **칸으로 분류**만 한다.

```
지금:  고객 질문 → LLM 해석 → 부품 DB 실시간 조합 → 답      (매번 다른 답, 검증 불가)
바꿈:  [배치] 격자 칸마다 견적 사전 생성 (매일 갱신)
       [실시간] 고객 질문 → LLM은 칸 분류만 → 미리 만든 견적 꺼내 설명   (같은 질문 = 같은 답)
```

- 경우의 수를 세는 대상은 **부품 조합이 아니라 질문**이다. 부품 23,000여 건의 조합은
  천문학적이지만, 고객이 물을 수 있는 칸은 수백 개다.
- 생성 배치는 **기존 recommend 엔진을 재사용**한다. 새 조합 엔진을 만들지 않는다.
- 저장 구조는 9/3 확정 골격 그대로 — **「완제품 = 이름을 얻은 견적」**, 슬롯+대안.

## 1. 벤치마크 요약 (2026-09-07 실측)

> 조사 방법: 세 사이트를 병렬로 실제 방문해 메뉴명·구간값·상품명을 수집.
> 원 보고 전문은 이 커밋의 근거 자료다. 아래 표의 값은 전부 그날 실측이며 스냅샷이다.

| | 다나와 | 오마이PC | 컴퓨존 |
|---|---|---|---|
| 미리 만든 견적 | 표준PC 32종/월 갱신 + 추천견적 15종 | 시리즈 브랜드 상시 700+종 | MD Pick 월 5종 + 라인업 상시 |
| 가격 티어 | 8구간 (40만 등폭, 50만~330만+) | 6구간 (라벨용 — 실판매가와 괴리) | 라인업별 6~8구간 |
| 용도 축 | 8용도 + 게임 타이틀 + AI 3종 | 9용도 + 게임 40종×6단계 | 용도×CPU클래스 결합 + SW 11종 필터 |
| 플랫폼 축 | 없음 (같은 칸에 병기) | **명시적** (GPU × 인텔/AMD 2분할) | 없음 (i5·라이젠5로 묶음) |
| 갱신 주기 | 매월 | 상시 | 매월 (MD Pick) |
| 티어 명칭 | 없음 (용도 그룹만) | 브랜드명 (벨류→…→플래티넘) | CPU 숫자 차용 (아이웍스3/5/7) |

### 격자 설계에 가져오는 결론 6

1. **3축(티어×용도×플랫폼)은 시장 검증 완료.** 셋 다 사실상 티어×용도. 플랫폼 명시는 오마이PC뿐 — 우리가 3축이면 차별점.
2. **티어는 저가를 잘게, 고가를 넓게** (컴퓨존 방식). 등폭 분할보다 수요 분포에 맞다.
3. **격자를 꽉 채우지 않는다.** 다나와도 게임용에 43% 집중. 수요 밀도로 비대칭 채움.
4. **AI 작업 용도 필수** (다나와 2026 신설 축). 게임 타이틀은 별도 레이어(§4).
5. **티어에 숫자 이름** (컴퓨존 3/5/7 방식) — 소비자가 서열을 즉시 인지.
6. **견적 생성만으로는 차별화 부족** (컴퓨존은 조립통계·호환검토 내장). 우리 강점 = 매일 갱신 + AI 칸 분류 정확도.

## 2. 티어 초안 — 7단계 (제안)

> 경계값은 **본체 단독 기준**(모니터·주변기기 제외 — 오마이PC의 실패에서 배움: 패키지
> 혼입으로 구간과 실판매가가 괴리). 아래 수는 제안이며 사장님 확정 대상이다.

| # | 티어명(안) | 예산 구간 | 폭 | 주 수요 (벤치마크 근거) |
|---|---|---|---|---|
| T1 | 팝콘 3 | ~60만 | — | 사무·인터넷 (다나와 표준PC 홈오피스 57만~) |
| T2 | 팝콘 5 | 60~100만 | 40만 | 온라인강의·캐주얼게임 (다나와 108만~130만 직전) |
| T3 | 팝콘 5+ | 100~150만 | 50만 | 온라인게임 주력 (다나와 게임용 하단 132만) |
| T4 | 팝콘 7 | 150~220만 | 70만 | 고사양게임 진입 (컴퓨존 게이밍추천 164만~) |
| T5 | 팝콘 7+ | 220~300만 | 80만 | 고사양게임·영상편집 (컴퓨존 MD Pick 205~228만) |
| T6 | 팝콘 9 | 300~450만 | 150만 | 4K게임·전문작업 (다나와 배그용 330~410만) |
| T7 | 팝콘 X | 450만~ | 오픈 | AI·워크스테이션 (컴퓨존 프리미엄 ~562만+) |

- 저가 3구간(~150만)이 촘촘하고 고가로 갈수록 넓다 — 컴퓨존 관행.
- 명칭 「팝콘 3/5/7/9/X」는 CPU 클래스 숫자 차용(컴퓨존 방식) + 중간 단계는 `+`.
  브랜드명(오마이PC 방식)으로 갈지는 명칭 결정 시 별도 판단.

## 3. 용도 초안 — 8종 (제안)

| # | 용도 | 벤치마크 대응 |
|---|---|---|
| U1 | 사무·인터넷 | 셋 다 1번 축 |
| U2 | 온라인게임 (라이트~중급) | 오마이 2D·캐주얼→3D·기본 |
| U3 | 고사양게임 (4K·하이엔드) | 오마이 3D·고급→4K, 다나와 배그용 |
| U4 | 영상편집·방송 | 다나와 영상/음향 + 방송용, 컴퓨존 방송용 |
| U5 | 디자인·3D설계 | 다나와 전문디자인·3D작업, 오마이 설계·3D도면 |
| U6 | 개발·프로그래밍 | 다나와 프로그래밍용, 컴퓨존 SW 필터(VS·안드로이드 스튜디오) |
| U7 | AI 작업 | 다나와 AI 3종(딥러닝·에이전트·크리에이터) — 2026 신설 축 |
| U8 | 저소음·컴팩트 (특수형) | 오마이 테마별(저소음·미니타워) — 후순위, 비워 두고 시작 가능 |

## 4. 격자 크기와 비우는 칸

```
7티어 × 8용도 × 2플랫폼(인텔/AMD) = 112칸
칸마다 대표 견적 1~2개 → 사전 생성 견적 약 150~200개
```

**비대칭 채움 원칙** — 말이 안 되는 칸은 비운다. 비우는 칸(안):

| 패턴 | 예 | 근거 |
|---|---|---|
| 저티어 × 고부하 용도 | T1~T2 × U3(고사양게임)·U7(AI) | 예산으로 불가능 |
| 고티어 × 저부하 용도 | T5~T7 × U1(사무) | 수요 없음 (다나와 홈오피스 최대 112만) |
| U8 전체 | 특수형 | 후순위 — 시작 시점에는 전부 비움 |

실제 시작 규모는 **60~70칸 · 견적 100개 안팎**으로 추정한다(수요 밀도 반영 후 확정).

**게임 타이틀 레이어 (격자 밖, 별도)** — 오마이PC의 「게임 N종 × 해상도·옵션 단계」
템플릿 방식. 게임 타이틀은 격자 칸이 아니라 **칸으로 가는 별칭(alias)**이다:
`「배틀그라운드 풀옵」 → T5×U3 칸`. 타이틀 목록만 유지하면 되고 견적을 따로 만들지
않는다 — 주기 갱신 비용이 늘지 않는다. 9/3 규약의 「게임 타이틀별 진열 축」과 일치.

## 5. 갱신 파이프라인 (안)

```
[매일 밤 배치]
① 격자 정의 읽기 (칸 목록 — 데이터, 코드 아님)
② 칸마다 recommend 엔진 호출 → 견적 생성 (슬롯+대안)
③ 전일 견적과 diff → 가격변동·품절 슬롯만 교체, 나머지 유지
④ 배치 ID·생성시각·엔진 버전 기록 → 「이 견적은 언제 기준」에 항상 답함
⑤ 검증: 칸별 예산 상한 준수 · 호환성 · 전일 대비 가격 급변 경고
```

- 실시간 경로에서 LLM의 일은 **칸 분류뿐** — 견적 조합 권한이 없다.
  같은 질문 = 같은 답. A-02 재현성이 격자 레이어에서도 성립한다.

## 6. 미정 — 사장님 확정 대기

| # | 무엇 | 이 문서의 제안 |
|---|---|---|
| 격자-1 | 티어 7단계 경계값 (§2) | 60/100/150/220/300/450만 |
| 격자-2 | 티어 명칭 방식 | 숫자 차용 「팝콘 3/5/7/9/X」 |
| 격자-3 | 용도 8종 목록 (§3) | U1~U8, U8은 비워 두고 시작 |
| 격자-4 | 칸당 견적 수 | 1~2개 (엔트리/권장 — 다나와 추천견적 방식) |
| 격자-5 | 갱신 주기 | 매일 (경쟁사는 매월 — 우리 차별점) |
| 격자-6 | 게임 타이틀 레이어 시작 목록 | 미정 — 컴퓨존 22종·오마이 40종 참고 |

> 이 문서는 격자 컨셉의 설계 초안이다. 확정되면 결정 로그에 등재하고,
> 그 뒤에 격자 정의 스키마·생성 배치 설계로 넘어간다.
