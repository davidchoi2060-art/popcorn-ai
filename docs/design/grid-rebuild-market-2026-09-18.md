# 격자 매트릭스 재구성안 — 시장 사다리 + 실판매 기준

작성 2026-09-18 · 근거 = 웹 조사(`pc_tier_ladder.md`) + 팝콘PC 실판매 234벌 + 우리 부품 카탈로그 실가

---

## 0. 왜 다시 짜는가

사장님 지적(2026-09-17):
> "사무용 저렴한 PC를 100만원 이상으로 살 사람은 없음"
> "단순질문에 선택지를 너무 넓혀서 알려준다"

실측해 보니 화면 문제가 아니라 **매트릭스가 시장과 어긋나 있었다.**

### 무엇이 어긋났나 — 실측

| 시장 구간(웹 조사) | 가격 | 실판매 | 우리 티어 |
|---|---|---|---|
| L0 사무·웹 | 40~70만 | 11벌 | **없음** |
| L1 가정·인강·캐주얼게임 | 70~130만 | 26벌 | **없음** |
| L2 FHD 게이밍 | 130~190만 | 36벌 | **없음** |
| L3 QHD 게이밍 | 190~290만 | 45벌 | T0·T1 |
| L4 고성능·4K입문 | 290~400만 | 44벌 | T0~T2 |
| L5 4K 하이엔드 | 400~700만 | 30벌 | T0~T4 |
| L6 워크스테이션·AI | 700만~ | 42벌 | T5 |

**시장 하위 3구간(실판매 73벌 · 31%)에 우리 티어가 하나도 없다.**
그리고 「사무·웹」이어야 할 T0 가 **212만원부터** 시작한다.

→ 70만원 사무 요청에 465만원이 나간 진짜 이유는 **T0 가 사무용이 아니라 QHD 게이밍급**이기 때문이다.

### 근본 원인

매트릭스를 **「우리가 조립 가능한 조합」**으로 채웠고, **「시장에서 팔리는 물건」**으로 채우지 않았다.
6용도 × 6티어 = 72칸을 기계적으로 만든 결과 「사무·인강 × 워크스테이션 = 1,344만원」 같은
**아무도 안 사는 칸**이 생겼다.

## 1. 바꾸는 원칙 — 용도는 축이 아니라 «단계의 이름»이다

**성능은 포함 관계다.** 상위 PC 는 하위 PC 가 하는 것을 전부 한다.
그래서 「사무용 1,344만원」은 말이 안 된다 — 그 돈이면 사무는 이미 포함이다.

    지금            용도(6) × 티어(6) = 72칸, 용도마다 독립 축
    바꾼 뒤          단계(7) 하나의 사다리. 용도는 그 단계의 «이름»이다

조사자 결론 원문:
> "사무·인강은 L0 에서 100% 충족 → L6 는 사무를 «포함»할 뿐.
>  용도는 **단계 이름이지 독립 축이 아니다**."

---

## 2. 새 단계 정의 (7단계)

가격은 **시중 실거래가**(웹 조사)와 **팝콘PC 실판매 중앙값** 두 축으로 검증했다.

| 단계 | 이름 | 시장가 | 실판매 | GPU 기준 | RAM | SSD |
|---|---|---|---|---|---|---|
| **L0** | 사무·웹 | 40~70만 | 11벌 | 내장(별도 GPU 없음) | 8GB | 512GB |
| **L1** | 가정·인강 | 70~130만 | 26벌 | 내장 760M/780M 또는 RTX 3050 | 16GB | 1TB |
| **L2** | FHD 게이밍 | 130~190만 | 36벌 | RTX 5060 8GB | 32GB | 1TB |
| **L3** | QHD 게이밍 | 190~290만 | 45벌 | RTX 5070 12GB | 32GB | 2TB |
| **L4** | 고성능·4K입문 | 290~400만 | 44벌 | RTX 5070 Ti 16GB | 32GB | 2TB |
| **L5** | 4K 하이엔드 | 400~700만 | 30벌 | RTX 5080 16GB | 64GB | 2TB |
| **L6** | 워크스테이션·AI | 700만~ | 42벌 | RTX 5090 32GB+ | 128GB | 4TB |

### 단계를 가르는 «새로 가능해지는 것» — 이것이 사다리의 뼈대다

    L0 -> L1   롤·발로란트·오버워치2 를 FHD 권장사양으로 (내장 760M 이 공식 권장 상회)
    L1 -> L2   **배틀그라운드 + AAA 패키지게임** (외장 GPU 의 진짜 계단)
    L2 -> L3   QHD 1440p 높음~최상 100~144fps · VRAM 12~16GB
    L3 -> L4   4K 입문 + 게임방송 원컴(방송+게임 동시)
    L4 -> L5   전문 CAD·3D(인증 드라이버) · 4K + 레이트레이싱 본격
    L5 -> L6   AI 딥러닝 학습(VRAM 32GB+) · 8K/VFX · 다중 GPU

⚠ 매 단계에 「한글·웹서핑」을 반복해 적지 않는다 — 당연히 포함된다. **차이만** 적는다.

## 3. 기존 6티어와의 대응

| 기존 | 새 단계 | 조치 |
|---|---|---|
| — | **L0 사무·웹** | **신설** (지금 없음) |
| — | **L1 가정·인강** | **신설** (실판매 26벌이 있는데 티어가 없었다) |
| — | **L2 FHD 게이밍** | **신설** (실판매 36벌) |
| T0 팝콘1 (212만~) | L3 QHD 게이밍 | 재정의 — 이름과 내용이 어긋나 있었다 |
| T1 팝콘2 | L3~L4 | 재정의 |
| T2 팝콘3 | L4 | 재정의 |
| T3 팝콘4 | L5 | 재정의 |
| T4 팝콘5 | L5 | 재정의 |
| T5 팝콘X (1,314만~) | L6 | 유지(가장 정확했던 티어) |

**게임 등급 대응**(조사자 확인): A/B/C 등급이 L2/L3/L4 → L3/L4/L5 → L4/L5/L6 로 1:1 대응한다.
S 등급만 GPU/CPU 비대칭이라 가격 단일축으로 표현 불가 — 별도 취급.

## 4. 칸 구성 — 헛칸을 만들지 않는다

### 지금
    비게임 6용도 × 6티어 = 72칸 (기계적 전개)
    게임 6등급 × 3해상도 = 36칸
    합계 108칸 — 이 중 상당수가 «아무도 안 사는» 칸

### 바꾼 뒤
    단계 7 × 플랫폼 2(인텔·AMD) = 14칸이 기본 축
    게임은 단계 위에 «해상도»만 얹는다(등급은 단계가 이미 표현)

**용도는 칸이 아니라 «그 단계를 부르는 이름»으로 쓴다.**
고객이 "사무용"이라 하면 L0 을 가리키는 것이지, 「사무용 × 6티어」가 아니다.

## 5. 예산 매칭 — 칸이 «범위»를 갖는다

### 지금의 결함
`grid_cells.budget_min = budget_max = 추천 variant 가격 하나`
→ 같은 칸에 46만원 가성비 구성이 있어도 「216만원짜리 칸」으로 취급돼
   70만원 고객에게 「초과」로 나간다.

### 바꾼 뒤
칸은 **시장 구간**을 갖는다(위 표의 시장가). 배치 결과가 그 구간을 벗어나면
**칸이 잘못된 것이므로 배치가 실패를 보고**한다 — 조용히 채우지 않는다.

## 6. 확신 없는 자리 (조사자가 명시한 것 + 하네스 판단)

1. **Adobe 공식 사양 미확인** — helpx.adobe.com 이 HTTP 403 으로 차단.
   영상편집 관련 단계 배치는 전부 **'추정'** 표기. 오토캐드·블렌더도 미수집.
2. **사장님이 보신 「30~40만원대」는 웹조사상 전부 중고·리퍼비시**
   (예: combuy 중고 i5-9400F 369,000원). **신품 바닥은 40만원대**이고
   우리 부품 최저 합산은 448,500원 — 직접 비교 대상이 아니다.
3. **우리 카탈로그 합산가는 시중 추천 견적과 동급 비교가 아니다** —
   우리 값은 「최저가 부품 탐색」 결과라 체급이 다르다.
   단 **실판매 완제품 중앙값은 시중과 거의 일치**(L4: 우리 332만 vs 시중 325~370만).
4. **L1 내장그래픽 fps 는 블로그 실측**이지 제조사 공식 수치가 아니다.
5. **L6 가 700만~2.25억 한 칸** — 사다리로서 너무 넓다. 쪼갤지는 판단 필요.
6. **L3 실판매 RAM 중앙값 16GB < 기존 T2 기준 32GB** — 우리가 파는 물건이
   우리 기준에 미달했다. 어느 쪽을 정본으로 삼을지 결정이 필요하다.
