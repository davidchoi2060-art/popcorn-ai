지도 누가 누구를 제약하는가

선 하나가 “이 둘은 서로 맞아야 한다”는 뜻이다. 메인보드가 허브이고, 케이스는 담는 그릇이라 안에 들어가는 거의 모든 것과 치수를 다툰다. 실선은 지금 검사하는 관계, 점선은 아직 검사하지 않는 관계다.

보드 중심 — 논리·전기 물리 공간 — 케이스 전력 냉각·간섭 아직 검사하지 않음

크로스체크 22쌍 무엇과 무엇을 비교하는가

지금 가장 크게 빈 곳
  • 메인보드 4항목이 0% — 지원 CPU 세대 · BIOS · M.2 규격 · EPS 커넥터. 원문(상품 스펙 텍스트)에 아예 없어 파싱으로는 못 채운다.
  • 치수 계열이 통째로 비어 있다 — GPU 두께·높이, 램 높이, 케이스의 GPU 최대 두께·파워 최대 길이. 그래서 “케이스에 들어가는가”를 길이 하나로만 판정하고 있다.
  • 보조전원 커넥터 — GPU 9% · 파워 22%. RTX 50 계열의 12V-2x6을 확인할 수 없다.
  • 쿨러 냉각 성능 38% — 규칙은 있는데 값이 없어 쿨러의 62%가 그 규칙에서 자동 탈락한다. 규칙이 있는 것과 작동하는 것은 다르다.
