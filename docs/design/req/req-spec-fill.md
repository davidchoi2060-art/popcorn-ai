⚠ **`api/dash.py` 주석이 이미 한계를 밝히고 있다** — *"세션에 직접 밀어 넣지 않는다 …
텔레그램과 같은 구조이고, 같은 한계를 갖는다 — 도중에는 못 읽는다."*

## ③ 못 찾은 것 — **지금은 어디에도 안 남는다**

채움 담당 규약(`.claude/agents/specfiller.md`)은 「검색했지만 못 찾은 것」을 따로 보고하게 하는데,
