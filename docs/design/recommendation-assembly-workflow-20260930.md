# 추천 판정과 고객별 조립 검수 분리

2026-09-30. 사용자는 흔한 규격 호환까지 모든 세부 사양을 사람이 채우느라 추천이 멈추는 문제를 지적했다. 실제 조립 중 문제가 발견되면 고객에게 전화로 변경을 안내하는 운영 방식도 반영하도록 승인했다.

## 적용 결과

16:50 KST 실제 DB 104개 구성, 고유 부품 201개를 재감사했다.

|분류|수|의미|
|---|---:|---|
|추천 가능 후보|52|이번 자동 사양 대조에서 추가 보완 없음|
|조건부 추천 후보|42|추천 조건을 만족하는 경우 후보로 활용하되 조립 확인 항목 보존|
|추천 전 보완|9|내장그래픽 근거 4개, 기본 쿨러 구성 식별 5개|
|우선 제외|1|현재 DB의 쿨러 소켓 지원 충돌(P119302)|

이전 52/51/1에서 42개가 확인 단계 재분류로 이동했다. 새로운 사양 42개를 확보한 결과가 아니며, 94개 모두의 추천 승인·출고 검증이 끝났다는 뜻도 아니다. 검토 승인 상태와 고객별 요구 조건은 별도로 적용한다.

## 판정 경계

- CPU/보드 소켓, DDR 규격, 명확한 장착·전원·판매 상태 충돌은 계속 추천을 차단한다. 필수 규격 미확인은 메모만으로 승인할 수 없으며 사양 근거를 보완해야 한다.
- 외장 GPU가 없다는 구성 표시와 CPU 내장그래픽 사양이 모두 확인될 때만 GPU 길이를 해당 없음으로 처리한다. 파워 정격이 확인된 구성의 전체 소비전력·연결 확인은 조립 단계로 보낸다. 전력 검사 자체를 통과로 바꾸지 않는다.
- CPU 쿨러 종류와 소켓 일치가 확인되고, 누락이 쿨러 냉각 수치 하나뿐일 때만 부하·온도·안정성 확인을 조립 단계로 보낸다. CPU 발열 값 누락이나 소켓 불일치는 제외하지 않는다.
- 보드 리비전/SSD 공급 품번 문제는 원문 지문·문구가 일치하는 검토된 자료에 한해서만 이관한다. 다중 모니터·특정 화면 단자·SSD 속도가 고객 필수 조건이면 다시 추천 전 확인 대상으로 취급한다.
- 수치 대조는 기존 `compat_rules`가 정본이다. `pc_review_policy.py`는 확인 단계만 구분한다. 정책 버전도 검토 근거 해시에 포함하여 옛 승인 재사용을 막는다.

## DB 반영 범위

기존 0119 테이블을 재사용하며 DDL은 없다. 부품 113685와 110899의 설명 JSON에 근거가 연결된 확인 단계만 추가했다. 원래 문제 문구와 사양값은 보존했다. 관련 구성 31개의 설명 해시·이력·리비전을 기존 잠금/지문 검사 도구로 동기화했다.

적용 전후 products, product_specs, compat_rules, 판매 제안, BOM 부품·수량, 구성 설명 본문과 승인 상태를 대조하여 불변임을 확인했다. 백업과 드라이런·적용·전수감사 증빙은 작업 PC의 `outputs/recommendation-assembly-20260930/`에 있다. 원문 변경 시 이전 단계 지정은 더 이상 유효하지 않다.

## 고객별 조립·전화 변경

등록된 실제 고객 견적 선택 → 조립 이슈 기록 → 준비된 변경안의 전후 부품·차액 확인 → 연락 시각, 설명한 영향, 동의/거절/미응답 기록 → 현재 변경안의 동의와 검증 확인 → 고객 견적 새 버전 적용 → 이슈 해결 기록 → 변경 구성 재검수.

- 기존 견적 버전은 수정하지 않는다. 고객별 기록이 공용 제품군이나 다른 고객 견적을 바꾸지 않는다.
- 전화 동의는 변경안 ID·리비전·BOM·금액에 묶인다. 미응답/거절, 다른 변경안, 오래된 검증은 적용을 차단한다. 연락을 기록했다고 곧바로 변경하지 않는다.
- 적용 시 호환성·판매·가격·고객 조건 검증이 모두 유효해야 한다. 이미 등록된 검증을 사용하며 이 API가 임의로 통과 결과를 만들지 않는다.
- 변경 후 고객 확정 기록은 기존 DB 트리거를 통해 제품군 등록 대기에 연결된다. 곧바로 공용 추천 제품군으로 자동 공개하지 않는다.
- 미해결 이슈, 미확정 변경안, 고객 미확정 상태에서는 검수 완료를 기록할 수 없다. 새 이슈나 구성 변경은 이전 검수 완료를 무효화한다.

관리자 `/api/admin/pc-quote-assembly` 조회/기록 API와 검토 패널을 추가했다. 기존 관리자 인증에 더해 쓰기 권한·교차 사이트·버전 경합을 검사한다. 전화 자체를 거는 기능은 없다.

**현재 실제 고객 견적은 0건이다.** 화면은 연결된 견적 없음으로 표시한다. 신규 고객 견적 등록, 변경안 생성 및 검증 결과 생성의 상위 흐름은 아직 별도 연결이 필요하다. 이번 작업을 고객 상담부터 판매·변경까지 전 과정이 연결된 것으로 해석하지 않는다. 공개 mvp2의 추천 경로는 이번 범위가 아니다.

## 관리자 화면

제품군 목록·요약에는 추천 상태와 조립 확인 건수를 구분한다. 전체 구성 → 검토 기록에서 추천 규격 대조, 조립 시 확인 항목, 추천 검토 근거, 고객별 조립·전화 기록 순서로 본다. 관리자 상담 검토 후보에는 조건부 항목을 전달하고 고객 필수 조건과 다시 대조한다. 공개 승인과 출고 승인은 별도다.
