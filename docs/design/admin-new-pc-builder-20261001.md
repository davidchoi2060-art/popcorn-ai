# 신규 조립PC 생성 · 대표 이미지 화면 설계 (2026-10-01)

## 범위
사용자가 신규 구성 화면 방향과 대표 이미지 기능을 승인했고, 이후 비용 절감을 위해 전체 부품 구성 및 호환성 검사가 끝난 뒤 생성하도록 정정했다. 이번 산출물은 관리자 공통 셸을 사용하는 4단계 클릭 시안이다. 실제 제품 등록/호환성 검사/LLM/이미지 API/업로드는 구현하지 않았다. localhost8785와 4개 PNG, 실제 N07 부품 읽기 스냅샷을 제공한다.

## 화면 흐름
1. 부품 구성: 빈 BOM에서 시작, 등록 판매 부품과 사내 보유 부품 구분. 실제 보유 수량 미연동을 재고 있음으로 표시하지 않는다. 내장그래픽과 CPU 기본쿨러는 확인된 사양으로 별도 선택한다.
2. 구성·가격 확인: 필수 부품/수량, CPU·메모리 규격, GPU/쿨러 장착 공간, SSD 슬롯, 전원 및 냉각 방식 점검. 새 구성의 조립비 30,000원 표시. 기존 완제품 포함 조립비는 중복 가산하지 않는다. 마진/가격정책은 기존 정본 재사용.
3. 설명: 확정한 BOM에 맞는 설명 초안과 선택 적용. 게임 FPS·작업 성능을 근거 없이 생성하지 않는다.
4. 대표 이미지·등록: 케이스 이미지 기반 생성, 실제 조립 사진 업로드, 결과 선택/재생성, 중복 BOM 확인, 검토 대기 등록. 추천 승인과 고객 공개는 별도.

## 이미지 호출 제한 — 사용자 정정 반영
- 부품 구성이 완성되어 있고 최신 BOM에 대한 호환성 검사 완료 상태가 유효할 때만 생성 버튼 활성화.
- 페이지 진입, 부품 선택, 설명 생성, 검사 완료만으로 자동 이미지 호출하지 않는다. 운영자가 비용 안내를 확인하고 생성 버튼을 직접 누른다.
- 서버도 필수 구성/수량/검사 완료/basis를 확인한다. 브라우저 체크값을 신뢰하지 않는다. 검사 미완료·불일치·구성 변경 후 오래된 검사로는 생성 요청 거절.
- 부품 또는 수량 변경 시 검사 무효화. 이미지 생성 대기/진행 중 BOM이 바뀌면 결과는 해당 이전 구성의 이력으로 남기고 새 구성 대표 이미지로 자동 적용하지 않는다.
- 케이스·냉각 방식·LED 설정은 최종 구성 근거로 고정/제한한다. 공랭 구성에 수랭을 임의로 그리지 않는다.
- 구성/표현 조건 fingerprint로 기존 이미지 우선 조회. 동일 요청 실행키와 진행중 작업을 중복 처리하지 않아 더블클릭/재시도 중복 과금 방지.
- 기존 적합 이미지 재사용, 비용 안내 후 명시적 재생성. 변경시 재확인 표시만 하고 자동 재호출하지 않는다.
- 생성 실패 시 작업상태/비용 로그와 재시도 제공. 사용자 요청 없이 무한 재시도하지 않는다. 이미지 없이 검토 대기 상품 등록 가능.

## 데이터 연결 설계 (미구현)
현재 pc_configurations/parts/offers/history/review와 부품 설명/이미지 정본을 재사용한다. 이미지 작업은 별도 실행 이력(작업ID, 임시구성ID 또는 제품군ID, BOM/시각조건 해시, 호환 검토 basis, 공급자/모델, 상태, 비용/사용량, 원본참조, 객체경로, 생성시각, 실패사유)을 두고, 확정한 이미지 자산ID만 제품군에 연결한다. 이미지 파일은 기존 비공개 상품미디어 저장소 정책을 재사용하고 원본/웹미리보기/썸네일을 구분. 실제 사진/AI조립예시 구분, 프롬프트 및 참조모델, 선택이력 보존. 고아 임시자산 정리 및 재사용 이력도 포함. 별도 테이블명과 마이그레이션은 구현시 기존 스키마와 중복검사 후 확정한다.

## 확인
시안에서 빈구성 및 구성완료/검사전 이미지 버튼 잠금, 검사완료 시 활성화 확인. 기존 N07 예시이미지 사용, 새 유료 생성 없음. 실제 가격은 표본 조회 시점의 개별 부품 판매가이며 운영 신규상품 가격 확정이 아니다.


## 2026-10-01 영상 기능 추가 승인
신규PC 및 기존104개(추가등록포함 현재105개)도 관리자가 영상 생성 버튼을 누르면 개별로 제작한다. 기본은 확정 대표이미지의 외형을 유지하는 6초 확대·이동 MP4이며 AI 영상모델 호출은 별도 요청 없으면 하지 않는다. 새 부품 구성/호환검사 완료 후 대표이미지를 확정하고 영상생성을 요청한다. 기존제품도 해당 최신 구성과 이미지 유효성을 확인한다.
영상 MP4/썸네일은 기존 GCS 상품미디어 저장소 정책에 맞춰 비공개 객체로 저장하고 DB에는 제품군ID, 원본 이미지 자산ID/해시, 영상 설정/해시, 상태, 객체경로, 크기·기간·체크섬·생성이력·선택버전을 연결한다. 저장 경로는 설계상 pc-configurations/{id}/videos/{job_id}/intro.mp4 (실제 경로규칙은 구현시 확정). 현재 이미지 읽기API는 상품이미지만 허용하므로 영상을 그냥 같은 endpoint로 제공하지 않고 별도 권한검사/스트리밍 및 byte-range 지원이 필요하다. 원본·영상 파일을 DB blob으로 넣지 않는다.
원본이미지 교체/구성변경 때 기존영상은 이력으로 보존하고 재확인 필요 표시. 같은 원본·설정·템플릿 버전 영상은 재사용, 중복 요청은 같은 작업을 반환. 대기/제작중/클라우드저장중/완료/실패 상태와 재시도·미리보기·다운로드 제공. 업로드실패를 완료로 보고하지 않으며 실제 파일존재·체크섬 후 완료 전환. 비용/리소스 안내, 자동전체생성 없음. 고객 공개는 기존 검토·공개 규칙을 따른다.
이번 변경은 시안 및 설계에 추가한 것. 신규PC 영상 패널 및 실제105개 기존 제품 목록/요청상태 UI 확인. 실제 MP4 생성·클라우드업로드·운영연결은 미구현이다.


## 광고형 영상 · 음악 선택 (사용자 수정 반영)
사용자가 초기6초 느린확대 샘플의 움직임과 사양설명 부족을 지적했다. 이후 회전/빠른화면전환/광고형움직임/마지막 팝콘AI 표기/활력있는 공개음악 선택을 요청했다. 기본 영상은 8초 광고형 샘플: 2초씩 완제품→확대화면→메모리·SSD→브랜드엔딩. 사양은 실제N07 CPU7500F/RTX5060 8GB/DDR5 32GB/NVMe1TB. 단일이미지 확대·2D기울임이며 실제3D회전/뒷면재구성은 아니다. 최종2초 팝콘AI 표기.

## 2026-10-02 대표 이미지 운영 기능
승인한 대표이미지 기능을 /admin2/pc-media?id=제품ID에 연결했다. 기존 제품군 작업공간/상세에서 진입. 전체 BOM과 현재 호환규칙·부품 원문/판매 상태, 케이스 사진·장착 쿨러 확인 후 운영자 버튼으로 1장 생성한다. 기존 GEMINI_API_KEY 및 google-genai 사용, PC_IMAGE_MODEL 기본 gemini-3.1-flash-image(공식 https://ai.google.dev/gemini-api/docs/generate-content/image-generation 확인). 기존 private product media bucket을 재사용하고 서버 ADC의 create/get 권한 사전 확인. 자동 유료호출/모델폴백 없음. 작업은 새 pc_media_jobs(0120)에 기록하며 BOM·가격·설명·revision·추천 승인은 변경하지 않는다. 요청UUID 재요청/진행중 중복 차단, 작업 중단 가능 표기, 실패 재생성 자동 실행 없음. 클라우드 저장 실패는 서버 임시 원본으로 저장만 재시도한다(서버 임시파일 유실 시 새 생성 필요). 대표선택은 현재 시각구성 해시 일치 필수. 구성·사진·냉각 정보가 바뀌면 이전 이미지가 목록/상세 대표에서 빠지고 관리화면에서 변경 안내, 가격만 변경되면 시각기준 유지.
