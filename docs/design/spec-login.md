# ⚠⚠ 결과 표시 — 서버 응답 14가지를 «그대로» 쓴다

**화면이 문구를 다시 쓰지 않는다.** 서버가 준 `message` 를 그대로 보여준다.

| 상황 | 코드 | 문구(서버가 준다) |
|---|---|---|
| 성공 | 200 `state:"active"` | 로그인됐습니다 → **0.9초 뒤 대시보드** |
| 임시 비밀번호 | 200 `must_change_password:true` | 임시 비밀번호로 로그인했습니다 — 비밀번호를 변경하세요 |
| 부트스트랩 | 200 `bootstrap:true` | 부트스트랩 계정으로 자동 승인됐습니다(관리자 권한) |
| 신규 신청 | 200 `state:"pending"` | 신청이 접수됐습니다 — 관리자 승인 후 이용할 수 있습니다 |
| 대기 재제출 | 200 `state:"pending"` | 승인 대기 중입니다 — 관리자에게 승인을 요청하세요 |
| 자격 불일치 | **401** `bad_credentials` | 이메일 또는 비밀번호가 올바르지 않습니다 (남은 시도 N회) |
| 잠금 | **429** `locked` | 로그인 시도가 많아 잠겼습니다 — N분 뒤에 다시 시도하세요 |
| 정지 | **403** | 정지된 계정입니다 — 관리자에게 문의하세요 |
| 비밀번호 미설정 | **403** `password_not_set` | 비밀번호가 아직 설정되지 않았습니다 — 관리자에게 발급을 요청하세요 |
| 이메일 형식 | **400** | 이메일 형식이 올바르지 않습니다 |
| 소셜·이메일 없음 | 제출 안 함 | 이메일을 먼저 입력하세요 |
| 이미 로그인 | `GET /auth/me` | 이미 로그인돼 있습니다 |
| API 연결 실패 | 네트워크 | API 서버에 연결할 수 없습니다 — 관리자에게 문의하세요 |
| 세션 만료 | **401** | 세션이 만료됐습니다 — 다시 로그인하세요 |

**결과 상자는 색조 넷으로 가른다**: 성공(초록) · 주의(노랑) · 대기(회색) · 오류(붉게).
⚠ **색만으로 말하지 않는다** — 코드와 문구를 함께 적는다.

## 결과를 «어느 쪽에» 띄우나

    신규 신청 · 대기 재제출   -> **우측(신청)** 상자에
    그 밖 전부               -> **좌측(로그인)** 상자에

⚠ 다만 §위에서 말한 대로 **제출은 한 곳으로 간다** — 잘못된 쪽에 넣어도 서버는 같게 판정하고,
화면은 **판정 결과에 맞는 쪽**에 결과를 띄운다.
