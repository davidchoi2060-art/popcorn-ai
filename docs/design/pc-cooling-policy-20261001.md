# CPU 포함 쿨러와 별도 쿨러 관리

2026-10-01 / 관리자 제품군 관리에 적용. 고객 화면과 실제 출고 승인은 별도다.

## 전수 대조 결과

현재 104개 BOM과 연결된 CPU 원문을 비교했다. 기본 쿨러 포함 명시 9개, 미포함 명시 또는 벌크 CPU 78개, 포장 내 포함 여부 미확인 17개다. 장착 구성은 별도 쿨러 99개, CPU 포함 기본 쿨러 5개다. 미확인 17개는 모두 별도 쿨러가 등록되어 있다. '멀티팩'이나 '정품'만으로 포함을 추정하지 않는다. 벌크 분류는 CPU 패키지 기준이며 공급처가 별도로 제공하는 쿨러까지 없다는 뜻이 아니다.

기본 쿨러 사용: P113193, P113334, P113838, P113843, P120220. 모두 CPU 121359, Ryzen 5 5500GT 멀티팩이다. 최신 DB 원문에 `멀티팩(Wraith Stealth쿨러 포함)`이 명시되어 있고 AMD 공식 MPK 냉각 솔루션도 Wraith Stealth다. 이전 '기본 쿨러 모델 미확인' 판단은 이 근거로 정정한다.

기본 쿨러 포함 CPU에 별도 쿨러가 등록된 4개: P113336, P90691, P97909, P99625. 기존 별도 쿨러를 유지하고 사용 이유를 검토한다.

## 관리·추천 기준

| CPU 패키지 | 실제 구성 | 처리 |
|---|---|---|
| 기본 쿨러 포함 | 기본 쿨러 | 알뜰 구성에서 활용. CPU 가격에 포함으로 표시 |
| 기본 쿨러 포함 | 별도 쿨러 | 기존 부품 유지. 저소음·지속 부하·외관 등의 선택 이유 확인 |
| 기본 쿨러 미포함 | 별도 쿨러 | 필수 부품으로 유지 |
| 기본 쿨러 미포함 | 쿨러 없음 | 별도 쿨러 추가 검증 전 추천 보류 |
| 포함 여부 미확인 | 별도 쿨러 | 실제 쿨러의 규격을 검토. 포장 정보만 불명확하다고 구성 전체를 보류하지 않음 |
| 포함 여부 미확인 | 쿨러 없음 | 원문·공급 구성 확인 후 결정 |

추천 구성이라는 이유만으로 별도 쿨러를 추가하지 않는다. 고객의 저소음·장시간 부하·LED 선호 등 필요와 검증 근거로 판단한다. 쿨러 교체만으로 FPS가 개선된다고 설명하지 않는다.

기존 판매 구성에서 쿨러를 임의 삭제하거나 완제품 가격에서 단품 가격을 빼지 않는다. 신규 견적은 실제 장착하는 쿨러 비용만 반영하고, 기본 쿨러와 별도 쿨러를 동시에 장착하는 구성은 만들지 않는다. 미사용 기본 쿨러 동봉 여부는 공급 형태와 사내 정책 확인이 필요하다. 가격·고객 동의는 기존 변경 견적/전화 동의 기록을 사용한다.

## 이번 코드 반영

`cooling_plan`을 CPU 포함 상태와 실제 장착 구성으로 분리하여 상세 API, 목록 데이터, 부품 구성·검토 탭에 제공한다. 현재 연결 원문의 해시가 유효해야 분류 근거로 사용한다. 가짜 단품 SKU나 기본 쿨러 가격을 만들지 않는다.

5500GT 멀티팩과 Wraith Stealth가 정확히 연결되는 기본 쿨러 구성에만 소켓 근거를 적용한다. 높이·냉각 TDP는 추정하지 않고 조립 확인으로 유지하며, 수랭 라디에이터 검사는 적용하지 않는다. 실제 별도 쿨러가 있으면 이 예외를 적용하지 않아 규격 불일치를 숨기지 않는다. 영향을 받는 5개 구성은 기존 승인 근거가 바뀌어 재검토 대상이며 자동 승인하지 않는다. 다른 구성의 승인 해시 형식은 유지한다.

기본 쿨러 구성에서 저소음·오버클럭·PBO·24시간·장시간 렌더링 요구가 명시되면 일반 조건부 추천을 그대로 사용하지 않고 추가 검토 대상으로 보낸다. 실제 소음 수준이나 온도 보장은 실측 근거가 필요하다.

## 남은 1개

P119302 / CPU 123027(225F 벌크) / 쿨러 123395(ABKO 자이로스 120X4 FRGB 블랙): 현재 DB 지원 소켓에 LGA1851이 없으나 최신 다나와에는 LGA1851이 표시된다. 이것만으로 실제 제품의 장착 불가를 확정할 수 없다. 제조사 자료와 실제 공급되는 브래킷의 일치 근거를 확보한 뒤 DB를 보완하거나 검증된 대체 쿨러 변경안을 처리한다. 이번에는 판매처 표기만으로 기존 사양을 덮어쓰지 않았다.
