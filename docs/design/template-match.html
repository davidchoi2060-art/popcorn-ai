메뉴별 화면 ↔ Phoenix 템플릿 대조표

좌측 메뉴 순서 그대로. 각 화면에 가장 가까운 템플릿 원본과 조합 후보를 답니다. Phoenix v1.22.0 · D:\phoenix_Templet\public

링크를 열려면 이 파일을 디스크에서 직접 열어야 합니다(탐색기에서 더블클릭). 템플릿이 D: 드라이브라 file:// 링크인데, 브라우저는 http:// 페이지에서 file:// 로 나가는 것을 막습니다.
우리 화면 링크는 로컬 API(127.0.0.1:8000)가 떠 있어야 데이터가 보입니다.
이 표는 "바꾸자"는 목록이 아닙니다. 2026-08-06 전수 감사에서 36화면을 직접 열어 본 결과, 대부분은 이미 충실했고 넷은 가져오려던 형태를 이미 구현하고 있었습니다. 참고 = 지금도 괜찮고 템플릿은 참고용 · 완료 = 이번에 손봄 · 후보 = 손볼 여지 있음 · 데이터 없음 = 화면이 아니라 원천이 빈 것
