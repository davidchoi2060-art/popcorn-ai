# §A 화면 브리프

## A-1 무엇

    화면 ID     ADM-GRD-010
    경로        /admin2/grid
    도메인      AI (사전 생성 견적 격자)
    보는 사람    운영자 · owner
    이 화면이 답하는 질문   「격자의 어느 칸이 채워져 있고, 각 칸의 견적은 언제 기준이며, 지금 팔 수 있는 상태인가?」
    여기서 내리는 결정      비었거나 낡았거나 검증 실패한 칸을 찾아 재생성을 지시한다.
                          칸의 견적을 열어 구성이 합당한지 확인하고, 문제가 있으면 해당 칸만 재생성한다.

## A-2 배경 — 격자가 무엇인가 (디자인이 알아야 할 최소)

조립 PC 견적을 고객 질문마다 실시간 생성하지 않고, **3축 격자의 칸마다 미리 생성해 두고
매일 갱신**한다. 축은:

    티어(7)      팝콘 3 / 팝콘 5 / 팝콘 5+ / 팝콘 7 / 팝콘 7+ / 팝콘 9 / 팝콘 X
                 (예산 구간: ~60만 / 60~100 / 100~150 / 150~220 / 220~300 / 300~450 / 450만~)
    용도(8)      사무·인터넷 / 온라인게임 / 고사양게임 / 영상편집·방송 / 디자인·3D설계 /
                 개발·프로그래밍 / AI 작업 / 특수형(시작 시점 전부 빈 칸)
    플랫폼(2)    인텔 / AMD

    총 112칸 중 의도적으로 비우는 칸이 있다(저티어×AI작업 등 — 예산상 불가능한 조합).
    시작 규모는 채워진 칸 60~70개 예상.

## A-3 실제 데이터 (재서 적음 — 2026-09-07 실측)

| 항목 | 원천 | 실측 | 최댓값·최장 |
|---|---|---|---|
| 칸당 견적 | POST /api/recommend (생성 배치가 저장) | 티어당 8슬롯 구성 | 부품 8개 |
| 부품명 | products.product_name | — | 최장 55자 표시 확인 (예: 「GIGABYTE 지포스 RTX 5060 EAGLE OC D7 8GB 제이씨현」) |
| 견적 총액 | 배치 저장값 | 77만~300만 실측 | 최대 8자리 (49,720,000원까지 가능 — 워크스테이션) |
| 생성 시각 | 배치 기록 | — | 「2026-09-07 15:52」 형식 |
| 배치 소요 | 실측 | 칸당 약 5초 · 전체 약 6분 | — |
| 칸 상태 | 배치 검증 | 정상 / 예산 상한 초과 / 재고 소진 슬롯 있음 / 생성 실패 / 빈 칸(의도) / 빈 칸(미생성) | 6종 |

    없는 데이터   격자 저장 테이블이 아직 없다(이 화면과 같은 물결로 설계된다).
                 그래서 지금 붙일 실데이터가 없다 — 전 수치는 data-bind 자리만 만들고
                 본보기 값은 자릿수만 맞춘다.
                 칸별 판매 실적·클릭 수는 이번 범위 밖(향후 사용예정으로 칸만).

## A-4 화면 구성 요구

핵심 뷰는 **격자판**이다:

    ① 격자판 (주 뷰)
       행 = 티어 7 (팝콘 3 → 팝콘 X, 위가 저가)
       열 = 용도 8
       플랫폼(인텔/AMD)은 상단 토글 — 토글하면 같은 격자가 플랫폼별로 전환
       칸 안에는: 상태(색+텍스트) · 견적 총액 · 생성 경과(「3시간 전」)
       칸 클릭 → ② 상세 서랍

    ② 칸 상세 서랍 (우측, data-keep)
       칸 좌표(팝콘 7 × 고사양게임 × AMD) · 상태 · 생성 시각 · 배치 ID
       견적 구성 표: 슬롯 8행 (부품명·가격) + 총액 + 예산 구간 대비 판정
       [이 칸 재생성] 버튼 · [견적 이력 보기] (향후 사용예정 — 자리만)

    ③ 상단 요약 바
       채워진 칸 N / 전체 M · 마지막 배치 시각 · 배치 상태(성공/일부 실패) ·
       [전체 재생성] 버튼 (되돌릴 수 없음을 화면이 먼저 말한다 — 확인 단계 필요)

## A-5 상태 — 전부 그린다

    빈 상태      배치가 한 번도 안 돈 상태: 격자 전체가 「미생성」. 첫 배치 안내 문구.
    로딩         격자 로딩 중 · 재생성 진행 중(진행 표시 — 칸 단위로 도는 것이 보이게)
    실패         401 세션 만료 · 500 · 부분 실패(112칸 중 3칸 생성 실패 — 실패 칸만 표시)
    경계         부품명 최장 55자 · 총액 8자리 · 「빈 칸(의도)」와 「빈 칸(미생성)」의 구분 —
                 이 둘을 같은 모양으로 그리면 운영자가 미생성을 정상으로 오인한다

## A-6 동작

    플랫폼 토글          인텔 ↔ AMD 격자 전환. 선택 상태 유지(data-keep)
    칸 클릭              상세 서랍 열림. 바깥 클릭으로 닫히되 서랍 안 클릭은 유지
    [이 칸 재생성]       확인 후 실행 · 진행 표시 · 완료 시 칸 갱신
    [전체 재생성]        되돌릴 수 없음 고지 + 확인 단계. 약 6분 소요를 미리 말한다
    행·열 머리 클릭      해당 티어/용도 줄 강조 (필터 아님 — 강조만)

## A-7 이 화면에서 하지 말 것

- 격자 축(티어 경계·용도 목록)을 이 화면에서 고치지 않는다 — 축 정의는 별도 관리
  (이 화면은 칸의 「내용물」을 다루는 자리다).
- 견적의 부품을 이 화면에서 손으로 교체하지 않는다 — 재생성만 있다. 손 교체를 열면
  「미리 만든 견적 = 엔진이 만든 견적」이라는 재현성 계약이 깨진다.

# §B 고정 계약 (그대로 따른다)

```css
:root{
  --bg:#F0F5F9; --surface:#F0F5F9; --card:#ffffff; --container:#E4ECF4; --container-low:#EAF2F8;
  --on:#111827; --on-variant:#64748B; --outline:#94A3B8; --outline-variant:#DCE7F2;
  --primary:#65A1D4; --primary-bright:#4A90E2; --on-primary:#ffffff; --primary-container:#DCE7F2;
  --secondary:#5071d5; --tertiary:#6E8FD6; --tertiary-container:#DCE7F2;
  --error:#C0392B; --on-error:#ffffff;
  --nav:#1E293B; --on-nav:#F0F5F9; --on-nav-muted:#94A3B8;
  --state-wait:var(--outline); --state-run:#D97706;
  --state-fail:var(--error); --state-done:var(--success);
  --success:#2f9e6d; --success-bright:#5fd6a0; --success-dark:#1c7a4d; --success-deep:#0f5132;
  --success-muted:#3d7a5c; --success-ink:#2c4c3c; --success-sage:#7aa891;
  --success-teal:#10a37f; --success-teal-bright:#6ee7d6;
  --success-container:#e9f6ef; --success-container-line:#d4e9dd; --on-success:#ffffff;
  --phoenix-font-sans-serif:var(--font);
  --font:'Noto Sans KR','Pretendard',system-ui,sans-serif;
  --font-head:'Noto Sans KR','Pretendard',system-ui,sans-serif;
  --font-num:'Noto Sans KR','Pretendard',system-ui,sans-serif;

  --sp-xs:4px; --sp-sm:8px; --sp-md:16px; --sp-lg:24px; --sp-xl:32px;
  --shadow:0 1px 2px rgba(15,23,42,.06),0 12px 30px rgba(15,23,42,.10);

```

> **색·여백·라운드·서체는 위 `:root` 변수만 쓴다. 임의 HEX·px를 새로 만들지 않는다.**
> 필요한 값이 없으면 **만들지 말고 「없다」고 알려 달라** — 토큰을 늘릴지는 우리가 정한다.

    상태색      admin2 팔레트는 초록 허용(A-45): 정상=--state-done · 실행 중=--state-run ·
                실패=--state-fail · 대기·미생성=--state-wait
    **색만으로 판정을 말하지 않는다 — 항상 텍스트를 병기한다**(색약 배려).

## B-2 산출물 형태

    형식        HTML 파일 하나 (CSS는 <style> 인라인)
    금지        React · Vue · Tailwind · 빌드 도구 — FastAPI + Jinja2 서버 렌더
    금지        외부 CDN 일체 (웹폰트·아이콘·차트 라이브러리·스크립트)
    서체        var(--font) · 숫자는 var(--font-num)
    아이콘      인라인 SVG 또는 자리만 표시
    셸          좌측 메뉴(LNB)·상단바는 그리지 않는다 — admin2 공용 셸이 감싼다.
                본문 영역만 그린다.

## B-3 마크업 계약

| 무엇 | 어떻게 |
|---|---|
| 최상위 | `data-screen-id="ADM-GRD-010"` `data-domain="ai"` |
| 서버에서 오는 값 전부 | `data-bind="키"` — 하나라도 빠지면 그 자리는 영영 가짜다 |
| 격자 칸 | `data-repeat="cells"` + 본보기 칸 하나만 |
| 견적 슬롯 행 | `data-repeat="items"` + 본보기 행 하나만 |
| 버튼 | `data-action="regen-cell"` `data-action="regen-all"` 등 |
| 예외 상태 | 미리 그려 두고 `hidden` |
| 선택 유지 영역 | 서랍·토글에 `data-keep="1"` |

## B-4 예시 값

    입력 폼      value= 비움. 셀렉트 기본 「선택하세요」
    표·카드      본보기 한 줄. 숫자는 자릿수만 맞추고 실제 값을 쓰지 않는다
    지어낸 수치   금지. 총액·건수는 전부 data-bind 자리
