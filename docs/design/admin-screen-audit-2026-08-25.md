## 매뉴얼에 쓰면 거짓이 될 화면 - 요약(중요도순)

1. 엑셀 다운로드 관리(#41) - 화면은 뜨지만 기능이 시스템에 전혀 없음(스키마 없음). "여기서 다운로드하세요"는 완전한 거짓.
2. 추천 기준 보기(#14) - "가중치를 설정"하는 화면이 아니라 코드 상수를 그대로 보여주기만 함. policy_weights 표는 죽은 테이블.
3. 부품 등급 관리(#13) - 등급을 매겨도 추천 엔진이 안 읽음(엔진 미연결, 자체 명시).
4. 대시보드(#1)·추천 가능 재고 현황(#15) - 이미 구축된 화면 3개(매입 견적·단가표 반영·재고 입고)를 "화면 없음"으로 잘못 안내. 근거: api/admin_ui_home.py의 _TARGET_PATH 딕셔너리(price_import·sourcing 키가 None), templates/admin/candidate_pool.html.j2:260,273, templates/admin/products.html.j2:270-272(정적 disabled). 화면이 생겨도 하드코딩된 안내문이 자동으로 안 풀리는 구조.
5. 쇼핑몰 동기화(#27) - 이름은 "동기화"지만 주기 배치가 없음. 인계 순간의 개별 확인일 뿐.
6. 인계 기록(#28)·유입 성과(#29) - 인계 이후(장바구니 도달·실구매) 추적 경로가 없음. "인계=판매"로 읽으면 안 됨.
7. 조립 호환 규칙(#11) - 열람만 가능, 편집 기능 없음(백엔드 신설 대기).
8. 용도별 최소 사양(#12) - 기존 용도의 필드 값만 변경 가능. 신규 용도·문구·순서는 안 됨.
9. 마진 정책(#24) - 분류별 마진 예외가 "가격 검토 승인"·"단가표 일일 반영"에는 안 먹힘(판매가 재산정에만 적용).
10. 가격 검토 대기(#23) - 검토 대기 발생 사유 3종 중 1종만 실제 동작.
11. 운영자·권한(#39) - "접근 IP 허용"은 아직 없음(향후 예정).
12. 상품 분류 관리(#2) - 되돌리기 API 없음, 노출 토글 무효.
13. 상품 사양 정의(#9)·공급처(#18) - "삭제"라는 표현 자체가 부적절(삭제 기능 없음, 비우기/중지만 가능).
14. 상품 일괄 등록(#5) - 적용 후 되돌리기 없음(owner 전용 대량 쓰기, 각별 경고 필요).
15. 오픈 단계 설정(#38) - 화면 매핑은 "확정 아님". 전환 축 스위치는 로컬 조작이 배포 서버(공유 DB) 고객 화면에 즉시 반영됨 - 매뉴얼 경고 필수.

## 눈에 띈 것(깊이 안 팜, 한 줄씩)
