## 3. ★ DB 정합성 결함 — 하네스가 실측 확인함

조사자가 DB를 교차검증하다 발견. **셋 다 견적에 직접 영향을 준다.**

### 결함 ① `usage_floors` 에 VRAM 조건이 **0개**

실측: 활성 조건이 `capacity_gb` 18건 + `required_power_watt` 6건뿐.
GPU를 **와트로만** 거르고 있다. 와트와 VRAM은 같은 축이 아니다 —
RTX 3060 12GB 가 반례(와트는 낮은데 VRAM은 크다).

VRAM이 중요한 용도가 실재한다: 라이트룸 16GB · AE 16GB · Stable Diffusion 12GB.
특히 **Stable Diffusion은 VRAM 부족 시 느려지는 게 아니라 실행 실패(OOM)** 한다.

### 결함 ② 정의와 데이터가 어긋남 — VRAM

`game_grade_resolution_tiers.note` 에 **"VRAM 8GB(원본 §3)"** 라고 적혀 있는데,
`games` 테이블에는 **VRAM 컬럼 자체가 없다.**
등급 정의는 VRAM 8/12/16 계단을 말하는데 원천 데이터가 그걸 못 담는다.

### 결함 ③ 대응 용도가 없는 분야 — 조사 대상의 28%

현재 `usage_floors` 용도 9종: AI작업 · 디자인 · 게임 · 캐주얼게임 · 고사양게임 · 사무인강 · 주식트레이딩 · 영상편집 · 3D그래픽

**없는 것: 개발 · 방송/스트리밍 · 음악**
조사한 프로그램 42종 중 **12종(28%)** 이 이 셋에 속한다(VS Code · Docker · OBS · 큐베이스 등).
고객이 "개발용 PC"라 말하면 지금은 받을 칸이 없다.

### 결함 ④ `office` 하한이 줌 권장보다 낮다
`office` RAM 하한 8GB < **줌 공식 권장 16GB**. 화상회의가 사무의 기본인데 하한이 못 따라간다.

### 결함 ⑤ `games` 표 자체의 구멍
- `game_id 17 'GTA'` — 버전 미특정·전부 null (GTA5 인핸스드 데이터 확보됨, 교체 가능)
- `game_id 23 '스팀 인디(통칭)'` — 실존 게임이 아님 (실제 인디 7종 개별 확보됨)
- 등급 배정이 22행에서 멈춤 — **신규 63종 미배정**
- 등급 정의표가 인용하는데 `games`에 행이 없던 4종(에이펙스·MSFS·시티즈2·AC섀도우스) — 확보됨

## 4. 스키마 제안 (양쪽 조사자 일치)

### 프로그램 — `games` 와 **분리**한 새 표
`software` + 자식표 `software_community_spec`. 컬럼명은 `games` 와 맞춘다.
근거: ①필요 필드 12개 추가(합치면 절반이 NULL) ②게임=1:1 조회 vs 프로그램=분야 집계
③갱신주기 상이 ④담당 분리

### 게임 — `games` 확장 + 자식표
1. **`game_measured_fps`** 별도 표 — 1:N 필연. `is_threshold`(TPU 결론이 "60fps 넘는 최저 GPU" 형태라
   **티어 사다리에 직결**) · `source_url` NOT NULL
2. **`rec_target_resolution` / `rec_target_fps` / `rec_assumes_upscaling` / `rec_assumes_frame_gen`**
   — 없으면 현재 `rec_gpu` 값의 절반이 오해를 부른다(몬헌 와일즈 사례)
3. **`min/rec_vram_gb`** — 결함 ② 해소
4. `game_popularity_snapshots`(시계열) · `game_ratings`(`sample_size` 필수)
5. `mapping_skip_reason` 을 벤더 분리 컬럼으로 — "파싱실패"와 "원래 없음"(로블록스) 구분

## 5. ⚠ 확신 없는 자리 — 견적에 바로 쓰기 전 확인 필요

1. **Puget Systems 수치는 워크스테이션 판매사 기준** — "프리미어 1080p도 RAM 64GB" 같은 값은
   일반 소비자에 과잉. **방향은 신뢰하되 숫자는 낮춰 잡을 것**
2. **AI 분야 커뮤니티 출처에 GPU 추천 상업블로그가 다수** — 수치는 일치하나 신뢰도 한 단계 낮음
3. **국내 커뮤니티 원문 확보가 부분적** — 검색 백엔드가 한국어 질의에서 반복 실패해 레딧 비중이 커졌다.
   한국 특수항목(HTS·한글·곰믹스)일수록 근거가 약하다
4. **`confidence:'추정'` 12건은 견적 규칙에 직접 투입 금지** (큐베이스·곰믹스·HTS·카톡PC는 공식 수치 전무)
5. **로직 프로는 macOS 전용** — 견적 로직에서 제외
6. **병목 5분류에 저장장치 축이 없다** — 영상편집에서 실제로 중요한데 표현 수단이 없다
7. **오픈크리틱 0/86** — API 유료·슬러그 매칭 신뢰도 낮아 의도적 전부 null
8. **실측 fps 6/86** — TechPowerUp 이 조사 중 403 봇차단. 나머지는 빈 배열(지어내지 않음)
9. **사양 null 11종** — 최우선 보완은 **리니지 클래식(PC방 3위)** 공식 사양 페이지 부재
