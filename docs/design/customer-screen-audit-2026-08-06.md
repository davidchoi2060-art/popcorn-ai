## ① 아이콘 이름이 글자로 노출된다 〔확정·9곳〕

Material Symbols 리거처가 폰트 없이 **텍스트 그대로** 보인다.

| 화면 | 노출되는 글자 |
|---|---|
| `main-landing` | `play_circle` `workspace_premium` `fact_check` `task_alt` `star_half` `alternate_email` |
| `s0-landing` | `format_quote` |
| `my-payments` | `credit_card` |
| `my-review-write` | `rate_review` |

버튼에 **"`play_circle` 작동 방식 보기"** 라고 적혀 있다. 첫 화면이다.

**원인:** A-30(2026-08-05)에서 외부 CDN 아이콘 폰트를 걷어냈는데, `su-icons.js` 의
매핑(`_map.json`)에 없는 글리프는 대체되지 않고 **이름이 그대로 남았다.**
회귀는 "외부 링크가 없는가"만 보고 **"글리프가 실제로 그려지는가"는 보지 않는다.**

나머지 9화면은 전부 정상 스왑된다 — 매핑에 있는 이름만 쓴 것이다.

## ② `호환성 5종` — 실제는 9종 〔확정〕

`main-landing` 히어로 아래 배지. `data-bind` 가 **없고** 마크업에 박혀 있다.

- 실제 활성 호환 규칙: **9종**(`compat_rules`)
- `GET /api/showcase` 가 **`rules: 9`** 를 내려준다 — 그리고 이 화면은 **그 API를 이미 호출한다**(200 확인).
- 바인딩은 `showcase_total`·`showcase_caption` 두 개뿐. `rules`·`pool` 은 받아만 놓고 쓰지 않는다.

CLAUDE.md 「화면 정직성」이 **이 문구를 예시로 명시**해 두었다:

> 목업 시절 연출(예: `poolN*0.6`, **'호환성 5종'**, 완화 칩 '+1,240개')이 LIVE 경로에 남아
> 서버가 모르는 수를 말하면 '모든 견적에는 이유가 있습니다'가 무너진다.

슬라이스 59에서 같은 화면의 다른 자리는 고쳤는데 **이 배지만 남았다.**

## ③ 마크업에 박힌 콤마 숫자 23곳 / 7화면 〔구조적 공백〕

| 화면 | 개수 | 예 |
|---|---|---|
| `s3-detail` | 8 | `4,769,000` `1,190,000` … |
| `main-landing` | 5 | `1,487,000` `645,000` … |
| `s2-result` | 3 | `1,250,000` |
| `vslot-demo` | 3 | `1,735,000` |
| `s0-landing` | 2 | `1,250,000` · **`26,480`** |
| `s1-session` | 1 | **`26,480`** |
| `s4-cart` | 1 | `1,735,000` |

**지금 화면에 보이는 값은 대체로 정상이다** — `s0` 를 열면 `3,308`(실제 후보 풀)과
`1,200,000`(showcase)이 바인딩돼 나온다. 마크업의 수는 덮인다.
**문제는 서버가 실패했을 때다.** 그때 저 수들이 사실처럼 남는다.

**구조적 원인:** 회귀 `[39] 서버가 없으면 지어내지 않는다` 가
`mockups/admin` **만** 검사한다(`tests/regression.py`의 `admin = os.path.join(ROOT, "mockups", "admin")`).
관리자 화면에서 금지한 것이 고객 화면에서는 아무도 막지 않는다.

> `26,480` 은 슬라이스 59가 "어느 값과도 불일치"로 지목한 그 수다. 실제 후보 풀은 **3,308**.
> **CLAUDE.md 본문에도 아직 남아 있다** — 「상태 관리 원칙」의
> "전체 부품(26,480개)에서 조건 통과 부품 수". 문서부터 고쳐야 한다.

## ④ 구현되지 않은 기능을 현재 사실로 말한다 〔판단 필요〕

`main-landing` 이 이렇게 적는다:

- "여러 AI가 의도를 교차 해석하고, 결정론 엔진이 재고·호환성·예산을 통과한 부품만으로 답을 만듭니다."
- "'조용한 화이트 4K편집' 같은 말을 **3개 AI가 교차 해석**해 의도를 정확히 잡습니다."

그런데 **실제 LLM 연동은 보류 상태**다(2026-07-21 결정). 내부 허브는 `API 모드 Mock`
이라 표시하고, 관리자 `AI 사용량·비용` 화면은 "실제 LLM 연동 보류로 기록이 쌓이지 않습니다"
라고 말한다. 즉 **같은 시스템의 다른 화면들은 '아직 없다'고 말하는데 첫 화면만 '한다'고 말한다.**

이건 버그가 아니라 **문구 결정**이다. 셋 중 하나여야 한다:
1. 오픈 전까지 표현을 "엔진이 검증"으로 낮춘다(엔진은 실재한다).
2. "준비 중"임을 밝힌다.
3. LLM 연동을 실제로 붙인다(별도 승인 필요).

**임의로 고치지 않았다.**

## ⑤ 초록 28종 / 8화면 〔미정 항목과 충돌〕

| 화면 | 초록 HEX |
|---|---|
| `s0-landing` `s1-session` `s2-result` | `#0f5132` `#1c7a4d` `#2f9e6d` `#3d7a5c` `#5fd6a0` |
| `index`(허브) `s3-detail` | `#0f5132` `#1c7a4d` `#2f9e6d` `#5fd6a0` |
| `s4-cart` | `#0f5132` `#1c7a4d` `#2f9e6d` |
| `main-landing` | `#10A37F` |
| `my-page` | `#1c7a4d` |

디자인 계약은 **"초록 없음(U-01 미정) → 통과=`--primary`, 위험=`--error`, 항상 텍스트 병기"** 다.
게다가 전부 **토큰이 아니라 원시 HEX** 라 "임의 HEX 금지"에도 걸린다.

`U-01`(success 토큰 추가 여부)은 CLAUDE.md 「미정」 목록에 있는 항목이라
**임의 결정 금지**다. 두 길뿐이다:
- 계약대로 28곳을 걷는다, 또는
- **U-01을 결정한다** — success 토큰을 추가하고 계약 문구를 고친다.

관리자 화면은 계약을 지키고 고객 화면은 안 지키는 지금 상태가 가장 나쁘다.
