# 관리자 제품군 표시 개수·검색 개선

2026-09-30 사용자는 표시 개수를 10·20·30개 등으로 고르고 이후에도 유지하길 요청했다. 매번 초기화되는 번거로움을 줄이고 검색도 편하게 개선하는 범위다. 고객단과 상품 데이터 변경은 포함하지 않는다.

- 기본 10개, 선택 10/20/30개. 목록 위와 아래에서 변경할 수 있고 두 선택은 연동된다. localStorage에 이 브라우저·사이트의 표시 개수를 저장한다. 새로고침과 새 탭 방문에도 복원하며 다른 PC·브라우저 동기화는 아니다. 잘못된 저장값은 10개로 복구하며 저장 불가 시 화면은 동작하고 유지 불가 안내를 표시한다.
- 검색창을 독립된 넓은 줄로 배치했다. 상품명·구성 ID·주요 사양과 현재 BOM에 연결된 부품명/코드를 검색한다. 띄어쓴 검색어는 모두 포함해야 하며 순서는 자유다. 영문 대소문자·모델명의 공백·하이픈은 정규화한다. RAM32GB, SSD1TB와 같은 전체 용량 별칭도 지원한다. 일반 32GB 검색은 해당 문구가 들어간 부품명도 포함할 수 있으므로 전체 시스템 용량에 한정하려면 RAM32GB를 쓴다.
- 검색 버튼 또는 Enter로 실행한다. 최근 검색어는 이 브라우저에 최대 5개를 저장하고 클릭 재사용/기록 지우기를 제공한다. 검색 조건은 sessionStorage로 현재 탭에서 돌아오거나 새로고침할 때 복원한다. 페이지 위치는 저장하지 않는다.
- ‘검색어 지우기’는 다른 필터를 유지하고, ‘검색 조건 초기화’는 검색과 필터만 지운다. 표시 개수와 최근 검색 기록은 초기화하지 않는다. 엑셀은 입력 중인 미실행 검색어가 아니라 마지막으로 조회 성공한 목록 조건을 사용한다.

검사: 관련 Python 단위검사 37개 통과(복합 검색, 부품 코드, 전각·모델명 정규화, 용량, 30개 API, 엑셀 동일 조건 포함), JS 문법·diff 검사 통과. 실제 DB를 읽는 로컬 화면에서 10→30 선택, 새로고침 30 유지, 하단20 변경과 상단 연동, 새 탭20 복원, 검색 조건 복원, 초기화 후30 유지, 최근 검색 재사용을 확인했다. H610M i312100 검색은 5개, 32GB RTX5060 검색은 16개 결과다. 브라우저 클릭 도구의 좌표 입력이 어긋나는 현상이 있어 검색 버튼은 키보드 Space 및 검색창 Enter로 실행을 검증했다. JS 오류 없음. 운영 UI 재검증은 배포 후 별도 기록한다.
