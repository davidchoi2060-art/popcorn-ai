## 2. 축이 둘인 이유 (2026-09-18 사장님 확정)

```
사양축 (GPU 필요)    "이 프로그램·게임이 돌아가야 한다"
                    게임 · 영상 · 3D · 디자인 · AI
                    -> 요구사양이 등급을 정한다

환경축 (GPU 불필요)  "몇 명이 · 어떻게 · 몇 개를 동시에 쓰나"
                    사무 · 개발 · 방송 · 음악 · 주식
                    -> 사용 환경이 등급을 정한다
```

근거: `software` 42종 실측 — 개발 6종 전부 `rec_gpu` 가 NULL(불요)이다. RAM 은 32GB 를
쓰면서도 GPU 사다리를 안 오른다.

## 5. ★ 사장님 지시 ① — 인강을 사무에서 뺀다

> "사무용과 인강용은 갈라도 될 듯.. 아마도 인강용이 더 낮은 등급이라고 생각이 들어"

**맞다. 지금 「인강·강의·수업」이 `office_simple` 안에 들어가 있다.**

인강은 사무보다 더 가볍다:

| | 하는 일 | 필요한 것 |
|---|---|---|
| 인강 | 영상 재생 + 필기 | **재생만 되면 된다** |
| 단순 사무 | 문서 작성·저장·인쇄 | 한글/워드 구동 |

인강은 **문서 프로그램조차 안 돌린다.** 웹브라우저에서 영상만 본다.

### 제안: `study` 신설

```
study (인강·학습)    RAM 8GB · SSD 250GB   ← 단순 사무와 같거나 낮게
낱말: 인강 · 강의 · 수업 · 학습 · 온라인 수업 · 자녀 · 학생 · 노트북 대신
```

⚠ **다만 실제로 더 낮출 수 있는지는 확인이 필요하다.** 이미 `office_simple` 이
RAM 8GB · SSD 250GB 로 우리 카탈로그 최저선에 가깝다. 더 낮추려면 CPU 쪽이어야 하는데,
그건 `spec_tiers` 소관이지 `usage_floors` 가 아니다.

**즉 하한은 같아도 «용도가 갈리는 것 자체»에 의미가 있다** — 화면이 "인강용"이라고
말할 수 있고, 근거 문구가 달라지고, 나중에 격자에서 다른 카드를 보여줄 수 있다.

## 6. ★ 사장님 지시 ② — 조립공임은 장바구니에서

> "공임은 최종 장바구니에서 마지막에 추가하는 걸로.."

**앞서 쓴 설계(`docs/design/assembly-fee-2026-09-18.md`)를 개정한다.**

| | 이전 설계 | **개정** |
|---|---|---|
| 붙는 곳 | 견적 총액에 포함 | **장바구니 마지막 단계** |
| `total` | `parts_total + 공임` | **부품 합 그대로** |
| 회귀 불변식 | 쪼갠다 | **건드리지 않는다** |
| 예산 판정 | 공임 포함 비교 | **부품값으로 비교** |

**이게 더 단순하다.** 견적 엔진·격자·회귀를 하나도 안 건드린다.
장바구니에서 한 줄 더하면 끝이다.

⚠ 다만 **고객이 견적 화면에서 본 값과 결제액이 3만원 다르다.**
그래서 견적 화면에 **"조립공임 30,000원 별도"** 를 반드시 표시한다 —
숨기면 "모든 견적에는 이유가 있습니다"를 어긴다.

## 7. 지금 판단이 필요한 것

### ⓐ 「업무용」을 어디에 둘 것인가
현재 **복합**에 있다. "사무용"만큼 모호한데 복합(비싼 쪽)으로 간다.
- 그대로 두기 / 단순으로 옮기기 / 양쪽에서 빼기(그럼 매칭 안 됨)

### ⓑ 인강을 갈랐을 때 하한을 실제로 낮출 것인가
갈라도 RAM/SSD 는 이미 최저선이라 **값은 같을 수 있다.**
- 값이 같아도 가른다(화면·근거·격자가 달라진다) / 값이 다를 때만 가른다

### ⓒ 「디자인」이 사양축인데 GPU 하한이 없다
표를 보면 `design` 만 사양축인데 GPU 조건이 없다. 포토샵 커뮤니티 VRAM 8GB 근거가
있으니 **GPU 하한을 넣을지** 판단이 필요하다.

### ⓓ 게임이 셋으로 갈려 있다
`game_casual`(550W) · `game`(550W) · `gaming_high`(650W) — 앞의 둘은 GPU·RAM 이 같고
SSD 만 다르다(500GB vs 1TB). **실질 구분이 흐리다.**
새 주사율 DB 가 들어왔으니 **해상도·주사율 축으로 다시 짤 수 있다.**
