## 두 안을 어떻게 합치나 — **1a 기준 + 1b 참조** (2026-08-14 사장님 재확정)

    처음   "두 화면을 다 참고해서 작업 처리" — 배치 선택을 제작자에게 열어 뒀다
    지금   **"1a 안으로 가되 다른 화면도 참조"** — 배치가 정해졌다

    1a 행 내 미리보기      **기준.** 값을 고치면 **그 행이 펼쳐져** 영향(N → M)을
                           보여주고 **그 자리에서** 확정한다
                           시연 케이스: AI 작업 GPU 650W → 750W · 후보 61 → 18 (0 아님)
    1b 시뮬레이터 패널      **탈락.** 우측 패널 배치는 쓰지 않는다
                           시연 케이스: 사무·인강 RAM 8 → 64GB · 후보 409 → **0** (위험)

**⚠ 배치만 1a 다. 1b 에서 «반드시» 가져올 것 셋이 있다:**

1. **후보 0 위험 경고** — 1a 는 「0 이 되지 않는」 안전한 경우만 그렸다. **0 이 되는 경우의
   붉은 경고와 「위험을 알고 저장」 버튼은 1b 에만 있다.** 행 내 미리보기 안에 그대로 넣는다
2. **「활성 · 비활성」 토글** — 끄면 판정에서 빠지고 **값은 남는다**
3. **「이 화면이 지키는 것」 5줄** — 아래 §문구에 전문이 있다

**1a 자신의 것도 빠뜨리지 마라:**
- **「+ 용도 만들기 — 향후 사용예정」** 잠금 버튼
- 그룹 헤더의 **「문구 편집 — 향후 사용예정」** 잠금
- 하단 고지(용도 문구는 **먼저 맞는 것 하나만** 적용된다 · 하한이 비면 그 용도의 필터링이
  통째로 사라진다 · 디자인·개발·사무는 GPU 하한이 없다)

## 반드시 들어갈 문구 (계약 — 그대로 쓴다)

**상단 안내 — GPU 는 성능 지표가 없다**
> GPU는 성능 지표가 없습니다. 권장 전원(W)을 성능의 대리 지표로 씁니다 — "고사양 게임 GPU 등급"이
> 아니라 **"그래픽카드 550W 이상"**처럼 숫자로 말합니다. 300W대 2.8만~19만원 · 550W대
> 29.7만~83만원 · 750W대 105만~256만원 가격대와 단조 대응하지만 완전한 성능 지표는 아닙니다.

**미리보기 — 위험하지 않은 경우**
> 후보가 61개 → 18개로 줄어듭니다. 0이 되지는 않아 견적은 계속 만들어집니다. 다만 이 용도의
> GPU 선택폭이 크게 좁아져, 예산이 낮은 요청에서는 불성립이 늘 수 있습니다.

**미리보기 — 후보 0 (강한 경고)**
> 후보가 0이 되어 이 용도로는 견적을 만들 수 없습니다.
> 사무용 RAM 하한을 잘못 올려 최저가 메모리를 전부 걸러 견적이 불성립했던 전례가 있습니다 —
> 그때는 이 경고가 없었습니다.

버튼: 위험 없음 → **「확인했습니다 — 저장」** · 후보 0 → **「위험을 알고 저장」**

**저장 안내**
> 저장하면 **다음 견적부터 적용됩니다 — 이미 만든 견적은 그대로입니다.** 미리보기 없이 바로
> 저장하는 경로는 없습니다.

**하단 (1a)**
> 용도 문구는 **먼저 맞는 것 하나만** 적용됩니다 — '고사양 게임'이 '게임'보다 앞에 있어야
> 이깁니다(순서를 바꾸면 어느 문구가 이기는지 조용히 뒤바뀝니다) · 하한이 비면 그 용도의
> 필터링이 통째로 사라집니다 · 디자인·개발·사무는 GPU 하한이 없습니다(그래픽 성능이 기준이
> 아닌 용도)

**하단 (1b)**
> 음수는 400으로 막힙니다 · 없는 하한은 404 · 후보 0은 오류가 아니라 강한 경고로 옵니다 ·
> 하한이 비면 그 용도의 필터링이 통째로 사라집니다

**「이 화면이 지키는 것」 5줄 (1b 우측 — 그대로)**
1. 미리보기 없이 바로 저장하는 경로를 만들지 않습니다 — 값 하나가 견적을 통째로 막을 수 있습니다.
2. 후보 0은 오류가 아니라 정상 응답 안의 강한 경고입니다 — 일반 안내와 같은 톤으로 흐리지 않습니다.
3. 저장은 다음 견적부터 적용됩니다 — 이미 만든 견적(스냅샷)은 소급 변경되지 않습니다.
4. 후보 카운터(S1)와 견적 엔진이 같은 표를 읽습니다 — 저장 직후 캐시를 비워 다음 견적에 반영합니다.
5. 하한을 걸 수 있는 필드는 지금 2종(GPU 권장 전원 W · 용량 GB)뿐입니다 — CPU 등급 같은 축은 아직 없습니다.

**활성 토글 안내**
> 끄면 이 하한이 판정에서 빠집니다 — 값은 남습니다

**잠긴 기능 안내**
> 용도 신설 · 매칭 문구 편집 · 순서 변경 — 향후 사용예정.
> 열기로 확정했지만 쓰기 API가 아직 없습니다. 순서를 바꾸면 어느 용도 문구가 이기는지
> 뒤바뀌므로, 붙일 때 그 경고를 함께 넣습니다.

## 이 화면이 왜 있나 (배신 사례)

화면은 오래전부터 용도 칩에 「저사양 GPU 제외」·「램 32GB↑ 우선」이라 적어 왔는데
**서버는 용도로 아무것도 하지 않았다.** 그래서 *"롤·배그 하려고요"* 에 **GT710 2GB** 가 나왔다 —
저소음 태그 + 최저가를 정확히 만족한 결과이고, **규칙대로 동작했지만 용도를 배신했다.**

그리고 반대 사고도 있었다 — **50만원 사무용에서 RAM 배분 10%(5만원)가 DDR4 램(최저 84,900원)을
전부 걸러 견적이 불성립했다.** 그때는 후보 0 경고가 없었다.

**이 화면은 그 둘을 다시 나지 않게 하는 자리다.**
