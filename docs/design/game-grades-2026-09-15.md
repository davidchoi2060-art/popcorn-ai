# 게임 22종 개별 웹검색 등급 조사 (조사자 산출물)

작성일: 2026-09-15 · 조사자: 읽기 전용(웹검색·문서작성만, DB·코드 미변경) ·
대상: `games` 재고 23종 중 **22종**(스팀 인디 통칭 1종은 특정 게임이 아니라 판정 불가로 제외).

**선행 문서와의 관계**: `docs/design/spec-tier-migration-plan-2026-09-14.md` §2-3은 원본
문서(`spec-tier-source-2026-09-14.md`) §3 "대표 타이틀" 목록에 **이름이 직접 등재된
경우만** 확정(6건)으로 인정했다. 이 문서는 그 방법과 별개로, **게임마다 개별 웹검색을
수행**해 공식 권장사양·벤치마크·전문 사이트 실측치를 원본 §2/§3의 등급 정의(VRAM
계단·목표 fps·해상도별 거동)와 대조하는 **독립된 2차 조사**다. 따라서 이 문서의
"확정"은 원본 §3 타이틀 목록과 다른 기준(실측 근거 대조)을 쓰며, 원본 문서의 6건
확정과 **일부 곂치되 더 많은 건을 확정할 수 있다** — 각 판정에 근거 URL과 대조 논리를
명시해, 지어낸 것과 실측 대조한 것을 구분할 수 있게 했다.

**등급 정의 재사용** (원본 §3, `spec-tier-migration-plan` §2-1 그대로):

| 등급 | 성격 | 핵심 기준 |
|---|---|---|
| E | 경쟁 이스포츠 | 60fps 이상·업스케일링 없음, 1080p 144fps+ 목표 |
| A | 일반 AAA(래스터) | VRAM 3단 계단 — 1080p 8GB·1440p 12GB·4K 16GB |
| B | RT 적용 AAA | 4K는 업스케일링 사실상 필수 |
| C | 패스트레이싱·UE5 극한 | 4K는 프레임 생성 없이 60fps 불가 |
| S | CPU 바운드 시뮬레이션 | GPU T2급/CPU T4급 비대칭 |

**확정 판정 기준(이 문서)**: 웹검색으로 얻은 **공식 권장사양 또는 신뢰할 수 있는
벤치마크 실측치**가 위 등급 정의 중 하나와 **명확하게 일치**하고, `games.rec_gpu`
재고값과 웹 조사 결과가 **서로 모순되지 않을 때**만 확정으로 표시한다. 다음 경우는
불확실로 남긴다: (1) 공식 최신 권장사양을 찾지 못함, (2) 검색 결과 간 수치 편차가 커서
신뢰 곤란, (3) 등급 정의 중 어느 하나와도 뚜렷이 일치하지 않음(등급 경계, 비대칭 부하
등), (4) 게임 자체가 미출시·사양 미공개.

## 개별 조사 상세

### 1. 리그 오브 레전드 (MOBA) — **E, 확정**

- 검색어: "리그 오브 레전드 권장사양 그래픽카드 2026"
- 근거: Riot 공식 지원 문서(support.riotgames.com) 권장 사양 GeForce GTX 560 /
  Radeon HD 6950. 재고 `rec_gpu`(GTX 560 / HD 6950)와 **완전히 일치**.
- 대조: 2011년대 카드로 실행 가능할 만큼 극단적으로 가볍다 — E등급 "1080p 144fps+"
  기준을 CPU 단일코어 성능만으로 가볍게 넘는 전형적 이스포츠 타이틀. 원본 §3 E등급
  대표 타이틀에도 직접 등재.
- 판정: **E 확정** (원본 명시 + 공식 사양 실측 일치, 이중 근거).

### 2. FC온라인 (스포츠) — **불확실**

- 검색어: "FC온라인 EA SPORTS FC 온라인 권장사양"
- 근거: 검색 결과 대부분이 EA 서구권 싱글 타이틀 "EA SPORTS FC 25"(권장: Ryzen 7
  2700X / i7-6700, RX 5600 XT / GTX 1660, RAM 12GB)로, **Nexon이 서비스하는 국내
  FC온라인(구 피파온라인4)과는 별개 엔진·별개 게임**이다. Nexon 공식 최신 권장사양
  페이지를 웹검색으로 특정하지 못했다.
- 재고 `rec_gpu`(GTX 460 / HD 6870)는 2010년 전후 카드로 매우 가벼우나, 이 값의
  발행 시점·최신성을 웹에서 교차 검증하지 못했다.
- 판정: **불확실** — 공식 최신 사양 미확인, 엉뚱한 게임(EA FC 25)과 혼동 위험이 커서
  등급을 강제하지 않는다.

### 3. 서든어택 (FPS) — **E, 확정**

- 검색어: "서든어택 권장사양 그래픽카드", "서든어택 권장사양 GeForce 9600GT i5-2500 공식"
- 근거: Nexon 공식 가이드(guide.sa.nexon.com/guide/21) 권장 사양 CPU i5-2500 /
  GPU **GeForce 9600GT**. 재고 `rec_gpu`(GeForce 9600GT)와 **완전히 일치**.
- 대조: 9600GT는 2008년 출시 카드로 롤(GTX 560)보다도 낮은 요구치 — E등급의
  "60fps 이상·업스케일링 없음" 기준을 CPU 클럭만으로 가볍게 만족하는 초경량 FPS다.
  원본 §3 타이틀 목록에 이름은 없지만, 실측 사양이 E등급 정의와 수치상 뚜렷이 일치.
- 판정: **E 확정** (공식 사양 실측 근거, 원본 미언급이지만 등급 정의와 명확히 부합).

### 4. 발로란트 (FPS) — **E, 확정**

- 검색어: "발로란트 권장사양 fps 벤치마크 1080p"
- 근거: Riot 공식(playvalorant.com/ko-kr/specs) — 최소/권장/고사양(144fps+) 3단
  체계로 목표 fps를 명시. 재고 `rec_gpu`(GT 730/R7 240)는 최소사양 수준으로 낮게
  잡혀 있으나 원본 §3 E등급 대표 타이틀에 "발로란트" 직접 등재.
- 판정: **E 확정** (원본 명시 + 공식 사양 목표fps 체계 일치).

### 5. 오버워치2 (FPS) — **E, 확정**

- 검색어: "오버워치2 권장사양 벤치마크 fps 그래픽카드"
- 근거: 405.kr·estmaster.net 등 FPS별 가이드가 1080p 경쟁 구간(100~600fps)을 저가
  GPU로도 달성 가능하다고 정리 — 발로란트보다 GPU 부담이 다소 크지만(팀전·이펙트)
  여전히 이스포츠 경량 범주. 원본 §3 E등급 대표 타이틀 "오버워치"(시리즈명) 등재,
  재고는 "오버워치2"로 동일 프랜차이즈.
- 판정: **E 확정** (원본 명시 + 조사 결과 이스포츠 경량 범주 재확인).

### 6. 로스트아크 (MMORPG) — **불확실**

- 검색어: "로스트아크 권장사양 그래픽카드 최적화"
- 근거: 블로그별 수치 편차가 크다 — 한 글은 "1080p GTX 1050, 1440p RTX 2070,
  4K RTX 2080"(2022년 작성, 오래됨)로, 재고 `rec_gpu`(GTX 1660 Super/RX 6600)와도
  다르다. 공식 최신 권장사양 페이지를 특정하지 못했고, 쿼터뷰 카메라 특성상 GPU
  부하 패턴이 일반 오픈월드 AAA(A/B/C)와 다르다는 점도 등급 매핑을 어렵게 한다.
- 판정: **불확실** — 자료 간 불일치가 크고 원본 체계(MMORPG 대표 타이틀 없음)에도
  해당 없음.

### 7. 메이플스토리 (MMORPG, 2D) — **불확실**

- 검색어: "메이플스토리 권장사양 그래픽카드"
- 근거: Nexon 공식 페이지(maplestory.nexon.com)는 "권장 사양"만 있고 최소 사양이
  없는 특이한 체계. 커뮤니티 정리로는 "GTX 1050 Ti 이상이면 대부분 콘텐츠 원활",
  "그래픽카드 자체가 크게 안 중요함"이 공통 의견 — 2D 게임 특성상 GPU 요구가
  거의 없고 CPU/RAM 비중이 더 크다.
- 판정: **불확실** — 매우 가벼워 E급과 유사한 부하로 보이나, 2D 렌더링 특성이
  원본의 3D 래스터/RT 기준 체계와 근본적으로 다르다. 재고 `rec_gpu`(GT 430/HD 5670,
  구형)도 이를 뒷받침하지만, "5등급 어디에도 정확히 안 맞는 경량 캐주얼" 결론은
  선행 문서와 동일하게 유지.

### 8. 던전앤파이터 (오리진) (액션RPG) — **불확실**

- 검색어: "던전앤파이터 오리진 권장사양 그래픽카드"
- 근거: 공식 시스템 요구사항 페이지를 웹검색으로 특정하지 못했다. 커뮤니티 글은
  "그래픽카드 중요도 낮음, 내장그래픽도 가능", 반면 2024년 유저 작성 글은 "6코어
  16스레드, 최대 클럭 5GHz 이상 CPU 필요"라고 상반되게 서술 — CPU 의존도에 대한
  의견이 갈린다.
- 판정: **불확실** — 공식 최신 사양 미확인, 커뮤니티 자료 간 불일치.

### 9. 디아블로4 (액션RPG) — **불확실**

- 검색어: "디아블로4 권장사양 그래픽카드 벤치마크"
- 근거: 블리자드 공식 최소 사양은 확인됨(i5-2500K/FX-8350, GTX 660급, 8GB RAM,
  720p 30fps 기준)이나, **권장 사양의 구체적 GPU 모델명**을 웹검색 결과에서
  일관되게 확인하지 못했다(블로그마다 "RTX 3060~4060" 추천 구성만 제시, 공식
  "권장" 칸 수치 아님). 퀘이사존 벤치마크(2023)는 66~70종 GPU 실측이 있으나 이는
  구세대 GPU 기준이라 현재 RTX 50세대·재고 `rec_gpu`(GTX 970/Arc A750/RX 470)와
  바로 대조하기엔 시차가 크다.
- 판정: **불확실** — 공식 "권장" GPU 모델 미확정.

### 10. 패스 오브 엑자일2 (액션RPG) — **불확실**

- 검색어: "패스 오브 엑자일 2 권장사양 그래픽카드 벤치마크", "Path of Exile 2 recommended specs i9-9900K RTX 2060 16GB official"
- 근거: 복수 사이트(pcgamebenchmark.com 등) 공식 권장 사양 — GPU RTX 2060 / RX
  5600 XT / Arc A770, **CPU i9-9900K**(또는 i5-10500/Ryzen 5 3700X로 보는 사이트도
  있어 소스 간 CPU 표기 편차 있음), RAM 16GB.
- 대조: GPU 요구치(RTX 2060, 1080p 8GB급)는 A등급 1080p 기준과 유사하나, CPU
  요구가 원본 S등급(CPU 바운드) 패턴처럼 유난히 높게 잡힌 소스가 있다 — ARPG인데
  왜 CPU가 무거운지(엔드게임 맵의 다중 이펙트·파티클 연산 추정) 명확한 공식
  설명을 찾지 못했다.
- 판정: **불확실** — GPU축은 A급, CPU축은 이례적으로 높아 단일 등급으로 못 묶는다.

### 11. 배틀그라운드 (배틀로얄) — **불확실**

- 검색어: "배틀그라운드 PUBG 권장사양 CPU 그래픽카드 fps", "PUBG 배틀그라운드 공식 권장사양 GTX 1060 라이젠"
- 근거: PUBG 공식 지원 문서(support.pubg.com)는 **최소/권장/최적 3단 체계**를
  쓴다. 확인된 것은 최소 사양(i5-4430/FX-6300, GTX 960 2GB, 8GB RAM)뿐이고,
  "최적 사양"(144fps+ 목표)의 구체 GPU 모델명은 이번 검색으로 원문 전체를
  가져오지 못해 확정하지 못했다. 재고 `rec_gpu`(GTX 1060 3GB/RX 580 4GB)도
  오래된 값으로 보인다.
- 판정: **불확실** — 권장/최적 사양 구체값 미확인. 원본 §3에도 배틀로얄 장르
  예시가 없다.

### 12. 사이버펑크 2077 (오픈월드RPG) — **C, 확정(단서 있음)**

- 검색어: "사이버펑크 2077 권장사양 최적 그래픽카드 fps 벤치마크"
- 근거: 여러 벤치마크 사이트(fpscalculator.net, pcoptimizedsettings.com) 실측 —
  **RT Ultra 프리셋**에서 RTX 4090조차 4K 40fps 수준(프레임 생성 없이는 60fps
  미달), RTX 4080은 1440p Ultra 47fps. 이는 C등급 정의 "4K는 프레임 생성 없이
  60fps 불가"와 **정확히 일치**. 일반(RT 없음) 옵션에서는 RTX 3070도 1080p High
  67fps로 훨씬 가볍다 — 즉 **그래픽 옵션(RT 유무)에 따라 실제 체감 등급이
  A~C 사이에서 크게 갈린다.**
- 원본 §3 C등급 대표 타이틀에 "사이버펑크 2077 RT 오버드라이브"로 명시.
