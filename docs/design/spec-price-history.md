## 구조 — 1a

**헤더** — `판매가 / 가격 이력` · ID 배지 · **「조회 전용」 배지** · 우측 문구
> "왜 이 가격인가"의 근거 원장입니다

**필터 줄**

    기간     시작일 — 종료일 (날짜 입력 둘)
    토글     [지금 값에 기여한 이력만] [되돌림 포함 전체]
    우측     전체 이력 N건 중 되돌려지지 않은 것만 기본 표시 · 최신 이력 YYYY-MM-DD

⚠ **기간을 바꾸면 좌측 상품 목록도 같은 기간으로 다시 계산된다.** 표만 바뀌고 목록이 그대로면 결함이다.

**좌 (296px) — 「이 기간에 변동이 있던 상품」** + 총 건수
행: 상품명 · 상품코드 · **이력 건수**. 고른 것을 시각적으로 표시.

**우 상단 — 선택 상품 카드**

    머리    상품명 · 상품코드 · 부품 종류 · 우측 「지금 판매가 N · 매입가 N」
    추이    막대 그래프 — 값 · 날짜
    범례    판매가 / 매입가 · 업체명 / **매입가 · 출처 미기록**
    고지    구간 축은 고정 길이가 아닙니다 — **실데이터 구간을 그대로 그립니다**

⚠ **공급처 미기록 옛 이력을 실제 공급처인 것처럼 지어내지 마라.** 별도 색 + 「출처 미기록」으로 밝힌다.

**우 하단 — 변동 표 7열**

    시각 · 구분(판매가/매입가) · 이전 · 이후 · 증감 · 사유(+ 누가) · 이동

    이전이 없으면   **「이전 값 없음」** · 증감은 **「설정」**
                   (2026-08-15 정정 — 원래 문구는 「(신규)」·「신규」였다. 아래 ⚠ 참조)
    되돌림 행       배경을 달리해 구분한다 (사유가 `_undo` 로 끝나는 것)
    증감            부호를 붙인다 (`+` / `−`)

⚠ **정정 — 「(신규)」·「신규」는 그때는 맞았다.** `new_price` 가 NOT NULL 이던 시절엔
`old_price IS NULL` 이 «항상» 최초 값 부여만을 뜻했다 — 값을 비우는 변경 자체가
스키마상 존재할 수 없었기 때문이다. **마이그레이션 `0050`(2026-08-15)이 `new_price`
의 NOT NULL 을 풀면서** 「비움」이 원장에 정식으로 남을 수 있게 됐고, 그 뒤로는
`old_price IS NULL` 이 **「비움 후 복귀」도 함께 뜻하게 됐다.** 계약 문구를 문자
그대로 지키면 그 행에 「(신규)」라는 **거짓**이 붙는다 — 이번 스키마 변경 전체가
없애려던 것과 같은 종류의 거짓이다.

**실측(확인자, 데모 상품 93720)**:

    history_id 29031   매입가 7,800 -> **비움**(new_price=NULL)
    history_id 29032   **비움 -> 7,801**(old_price=NULL, new_price=7,801) — 이 행은
                       «복귀»이지 「신규」가 아니다. 그런데 `old==null` 조건만 보면
                       「(신규)」·「신규」로 잘못 표시된다

「이전 값 없음」·「설정」은 "이전 값이 없다"는 사실만 정직하게 말하고, 그 원인(최초
부여인지 비움 후 복귀인지)은 단정하지 않는다.

⚠ **함께 남긴다 — 검증이 스코프 밖 변경을 잡았다.** 제작자는 「이전」 열만 고치겠다고
신고했는데, 같은 diff에 「증감」 열(`price_history.html.j2:766`, 원래 코드
`it.old==null ? '신규' : ...`)도 함께 바뀌어 있었다. 확인자가 이 두 번째 변경이
제작자의 스코프 자기신고에 없었다는 것을 짚었다. **하네스 판정: 둘 다 유지한다** —
근거가 같다(`old==null`이 최초 부여·비움 후 복귀 두 원인을 갖게 된 것은 「증감」
열에도 똑같이 걸린다). 다만 「신고 안 된 변경이 하나 있었고 검증이 그것을 잡았다」는
사실 자체는 여기 남긴다 — 다음에 같은 일이 있을 때 이 기록이 재료가 된다.

**하단 고지**
> 기간을 바꾸면 좌측 상품 목록도 같은 기간으로 다시 계산됩니다 · 날짜 형식이 틀리면 **400** ·
