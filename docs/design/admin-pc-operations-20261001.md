# 관리자 운영 흐름과 변경 알림 — 2026-10-01

## 범위
사용자 ‘승인’에 따라 관리자 저장·검토 흐름 확인, 보완 사유 정리, 상품 DB 변경 감지를 구현했다. 고객 화면과 공개 전환은 후속이다. 실제 제품 가격·BOM·승인 상태를 일괄 변경하지 않았다.

## 확인과 수정
- N02~N05는 GPU 행이 없는 신규 내장그래픽 BOM이다. 외장 GPU 없음 + 구성에서 내장 명시 + CPU 내장그래픽 사양 확인 조건으로 GPU 길이 검사를 해당 없음 처리한다. 정격이 확인된 파워의 실제 시스템 전력은 조립 확인 항목으로 유지한다. 미확인 CPU/외장 GPU가 있는 BOM은 이 예외를 적용하지 않는다.
- 전체 104개: 추천 가능 후보 52 / 조건부 후보 46 / 보완 5 / 제외 1. 후보 분류이며 실조립·출고 또는 개별 검토 승인과 다르다.
- 보완 5개 P113193/P113334/P113838/P113843/P120220: ‘기본 쿨러’ 가상 항목 101309의 실제 납품 모델이 미확정이다. 소켓·냉각·높이·장착 사양을 임의 채우지 않았다.
- 제외 P119302: ABKO 120X4 등록 지원 소켓에 LGA1851이 없다. 실제 지원 브래킷 근거를 확보하거나 확인 가능한 대체 쿨러를 관리자 부품 변경에서 선택해야 한다.
- 검토 승인 후 목록에서 잘못 ‘근거 변경’으로 표시되던 오류를 수정했다. 목록은 전체 제품군의 RowMapping을, 상세는 해당 BOM의 dict를 해싱하던 차이를 해소했다. 해당 BOM 행만 정규화·정렬하여 비교하며 무관한 부품 변경은 승인에 영향을 주지 않는다. 정책 버전은 recommendation-assembly-v2이며 이전 정책 승인은 새 검토가 필요할 수 있다.

## 관리자 화면
- 공통 보완 항목을 펼치면 같은 검사 사유의 구성 ID를 함께 볼 수 있다. 제외 사유와 근거 부족은 별도로 묶는다. ID 선택으로 해당 검토 화면을 연다.
- 가격·판매 확인 필터, 목록 배지, 상세 대조 내용, 엑셀 Q열 알림을 추가했다.
- 최신 상태 조회는 현재 DB를 읽는다. 외부 판매처나 공급처를 새로 크롤링하지 않으며 실제 재고를 보증하지 않는다.

## 가격·판매 변경 감지
기존 products / product_price_history / pc_configuration_offers / history를 사용한다. DDL 없음.
- 현재 부품 및 원본 완제품의 판매 표시 확인.
- 원본 완제품은 저장 기준가와 해당 완제품 DB 판매가를 대조한다. 옵션 기준 차이는 사람이 검토한다.
- 신규 구성은 현재 단품가 × 수량 + 등록 조립비와 저장가를 대조한다. 기존 견적에 단품 차액을 적용한 ADMIN 변경 견적에는 단품 합계 방식을 적용하지 않는다.
- 부품 판매가 이력은 최초 구성 기록 시각 이후 또는 최근 승인 이후만 표시한다. 날짜만으로 수집 당일 과거 가격 변경을 새 변경이라고 오인하지 않는다. 최초 시각이 없는 경우 이력 알림을 추정하지 않으며 직접 가격·판매 대조는 유지한다.
- 설명 저장이나 검토 초안 저장으로 가격 변경 알림을 해제하지 않는다. 승인 이후 과거 이력 알림은 사라지지만 실제 저장가 불일치·품절은 계속 표시한다.
- 가격 자동 덮어쓰기 없음. 기존 상품 업로드/가격 갱신이 DB에 반영된 다음 목록 조회 시 영향 상품을 확인한다. 수동 mall sync를 무인 스케줄로 전환하지 않았다.
- 초기 대조에서는 가격·판매 알림 0개. 이는 DB 내부 일치이며 외부 최신 가격이나 출고 확인 결과는 아니다.
