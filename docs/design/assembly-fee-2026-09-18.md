# 조립공임 30,000원 — 견적 반영 설계

작성 2026-09-18 · 사장님 확정: "조립공임 이라고 생각하고 30000원으로 맞추면 됨"

---

## 1. 근거

사장님 실판매 사무용 견적 6벌 전부에 같은 항목이 부품처럼 들어 있다:

```
구동 테스트[윈도우/3D마크/각종 단자 점검]   29,000원   (6벌 전부 동일)
```

사장님이 이를 **조립공임 30,000원**으로 정리하라고 확정했다.

### 하네스가 처음에 틀린 판단을 했다

처음엔 "이건 서비스라 격자에서 빼고 주문 단계 옵션으로 두자"고 제안했다. **틀렸다.**

조립공임은 PC 를 사면 **반드시 내는 돈**이다. 빼놓으면 고객이 468,160원인 줄 알고
결제하러 갔다가 498,160원을 본다. 그건 **"모든 견적에는 이유가 있습니다"를 어기는 것**이다.

화면 정직성 규약과 같은 문제다 — 화면이 말하는 수와 실제로 내는 돈이 달라선 안 된다.

---

## 2. 현재 상태 (실측)

```
조립공임 개념      코드에 없음 (grep 결과 0건 — '조립'은 주문 상태 라벨로만 쓰임)
견적 총액 계산      api/recommend.py:1161  raw_total = sum(sale_price)
                  api/recommend.py:1200  total     = sum(sale_price)
회귀 불변식        tests/regression.py:391   [tier] 부품 가격 합 = 총액
                  tests/regression.py:4857  showcase 부품 합 = 총액
```

**`총액 = 부품 합`이 코드와 회귀 양쪽에 박혀 있다.** 여기에 공임을 그냥 더하면 회귀가 깨진다.

---

## 3. 설계 — 총액의 정의를 바꾼다

### 바꿀 것

```
지금   total = 부품 합
바꿈   parts_total = 부품 합
       assembly_fee = 30,000
       total = parts_total + assembly_fee
```

### 응답 구조

```json
{
  "parts_total":   468160,
  "assembly_fee":  30000,
  "total":         498160,
  "fee_note":      "조립공임 (조립·윈도우 설치·3D마크 구동 테스트·단자 점검)"
}
```

### 회귀 불변식 개정

```
기존   sum(items.price) == total
개정   sum(items.price) == parts_total
       parts_total + assembly_fee == total
```

**불변식을 없애지 않고 «쪼갠다».** 둘 다 성립해야 통과다 —
공임이 조용히 사라지거나 두 번 더해지는 사고를 막는다.

---

## 4. 예산 판정과의 관계 ★ 중요

고객이 "70만원 예산"이라 말하면 그건 **최종 결제액**이다. 공임을 뺀 부품값이 아니다.

```
예산 판정   budget.cap 과 비교하는 값 = total (공임 포함)
            parts_total 로 비교하면 3만원씩 초과를 감추게 된다
```

`budget.verdict`(within/over/over_by) 계산에 **공임 포함 총액**을 쓴다.

---

## 5. 격자(grid_quotes)에도 같이 반영

```
grid_quotes.total          지금은 부품 합
                           -> 공임 포함으로 바꾼다
```

격자 카드가 말하는 가격과 실제 결제액이 달라선 안 된다.
`tools/grid_generate.py` 재실행 시 반영된다.

---

## 6. 값을 어디 둘 것인가

**하드코딩하지 않는다.** 공임은 사장님이 바꿀 수 있어야 한다.

후보:
- `pricing_policies` 표에 행 추가 (마진 정책이 이미 여기 있다)
- 또는 `ops_switches` 계열 설정값

→ 마진 상속이 `pricing.resolve_margins` 단일 원천인 것과 같은 규칙:
  **공임도 한 곳에서만 읽는다.** 화면·엔진·격자가 각자 30000 을 적으면 언젠가 갈라진다.

```

조립공임          30,000
─────────────────────
합계             498,160
```

조립공임이 무엇을 포함하는지 한 줄로 밝힌다 —
사장님 견적서 문구를 그대로 쓴다: **조립 · 윈도우 설치 · 3D마크 구동 테스트 · 단자 점검**

## 8. 적용 범위

| 대상 | 반영 |
|---|---|
| 견적 API (`/api/recommend`) | O |
| 격자 카드 (`grid_quotes.total`) | O |
| 쇼케이스 (`/api/showcase`) | O |
