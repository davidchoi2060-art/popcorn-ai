## 상품 유형 분기 기준

| 유형 | 원천 | 구매 행동 |
|---|---|---|
| 일반 완제조립PC·완성 제품 | `GET /api/customer/pc-catalog`(목록·상세·비교·선택·대화 카드 type `pc`) | **「팝콘PC몰에서 구매하기」** — 그 상품의 `mall_url` 새 창. 견적 보관·상담·연락처·동의 선행 없음 |
| AI 슈퍼컴퓨터 | `/api/customer/supercomputers`(대화 카드 type `ai_device`) | `supercomputer.html` → `supercomputer-inquiry.html` 견적 문의(변경 없음) |
| AI 패키지 | `ai-packages.html` · `ai-consult.html` · `ai-inquiry.js` | 도입 상담(변경 없음) |

- `pc-catalog` 안의 「AI·고성능 PC」 워크스테이션은 **일반 몰 판매 상품**으로 본다(몰 상품번호·`mall_url` 이 있다). 기본값이며 사장님이 달리 정하면 바꾼다.
- 링크 검증 = `PrecisionCatalog.mallBuyUrl()`(`mockups/mvp4/assets/js/live-catalog.js`): `https://www.popcornpc.co.kr/shop/system_detail.html` 이고 `pd_no` 가 그 상품 ID 와 같을 때만. 몰 홈·검색·다른 상품번호면 버튼을 비활성 「구매 링크 확인 필요」로 둔다.

## 일반 완제품 — 빠진 것과 남은 것

- 빠짐: 상세·비교·선택·대화 인계의 「견적 보관하기」「구매 상담 신청」, 저장 폼(전화·동의), 보관 견적에서 상담으로 가는 경로.
- 직접 주소 진입: `?screen=save|quote|consult&id=<일반 PC>` 는 몰 구매 안내로 바뀐다(폼·POST 없음). `?screen=consult&quote=<id>` 는 「보관한 견적은 그대로 있어요」 안내만 낸다.
- 남김: 비교 담기 · 옵션 변경(같은 몰 상품 링크) · 기존 보관 기록(삭제·변환 없음, 목록에 몰 구매 링크) · 상품 없는 일반 문의(`?screen=consult`, 「문의하기」).
