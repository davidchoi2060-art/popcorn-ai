# ASUS 3종 고객 구성표 선정 근거

2026-11-06 · PC2 Claude. 선정표 코드 = `api/asus_campaign.py`의 `BUILD_PICKS`, 고객 응답 키 = `build`.

**이 표는 고객 화면에 보일 대표 제품을 정한 것이다. ASUS 협의, 공급 확인, 실조립 호환 판정이 아니다.** DB의 `parts[].options`, 가격, 상태, 비고는 그대로 두었다.

## 판단 순서

문서 우선순위는 v4 보완전달서 → 판매중 가격 확인표(2026-11-05) → 문구 v2 → v3 개발전달서다.

1. 모델 headline(v3 §구성표, v4 「정확한 Ti/OC/용량 동일 유지」)과 맞지 않으면 뺀다.
2. 확인표가 「선정 금지」「확정 불가」로 적은 후보를 뺀다. 가격이 낮아도 고르지 않는다.
3. 확인표가 「대안」이 아닌 구체 후보로 적은 제품을 고른다.
4. 그래도 여럿이면 확인표의 판매중 최저가 기준을 쓴다.

`options[0]`은 기준이 아니다. 문서·업무용 파워의 `options[0]`은 선정 금지된 850G이다.

## 전후 대조

수량은 "역할별 1개"라는 구성 원칙과 제품명의 물리 구성을 옮긴 값이다. RAM의 `[32G×2]` 등은 모듈 수이며 중복이 아니다.

## 여전히 확정이 아닌 것

선정으로 해소되지 않았고, 고객 화면에는 「최종 구성과 호환 범위는 상담에서 안내」로만 표시한다.

| 항목 | 상태 |
|---|---|
| RTX 5080, RTX 5090, PRIME LC 360 ARGB | 2026-11-05 조회 기준 판매중 동일 상품 없음. 공급 미확인 |
| 삼성 128GB [32G×4] | 4개 장착 시 동작 속도와 ProArt 보드 QVL 미확인. 제품명의 DDR5-5600이 실제 동작 속도라는 뜻이 아님 |
| BIWIN M350 | 확인표가 「최종 SKU 미확정」으로 적음. Crucial과 표시가 차이는 600원 |
| TUF 1000W GOLD, STRIX 1200W Platinum, 850W Platinum | 파워 3종 모두 DB 상태는 `check`. 1000W·1200W의 세대·커넥터는 확인 전 |
| 조립 호환 | GT502 표기 치수 안이라는 근거만 있음. 케이블 굽힘, 라디에이터·메모리 간섭은 실조립 확인 전 |
| 시스템팬, 조립비, 배송비, 운영체제, 합계 | 미정 또는 별도 |
| 399만·599만·1,299만원 | 기획 검토가. 이번 선정의 합계가 아님 |

## 데이터가 바뀌면

표시명, 몰 번호, 제품명이 선정표와 모두 같고 상태가 `sale`·`candidate`·`check`·`supply`일 때만 제품을 낸다. 그 밖에는 다른 후보로 넘어가지 않고 그 줄을 「상담 시 안내」로 바꾼다. 대표 제품을 바꾸려면 `BUILD_PICKS`, 이 문서, `tests/test_asus_parts_selection_20261106.py`를 함께 고쳐 배포한다.
