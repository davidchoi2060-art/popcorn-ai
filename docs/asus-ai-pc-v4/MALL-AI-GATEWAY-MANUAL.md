| 열 | 뜻 |
|---|---|

윈윈(팝콘PC)에 올라 있는 상품의 판매가, 원가, 딜러가 등을 조회하는 방법이다. 두 가지로 쓴다. (낡음 2026-11-17: 원가와 딜러가는 더 나오지 않는다.)

| 방식 | 언제 쓰나 | 도구 |
|---|---|---|
| **수동** | 필요할 때 몇 개를 바로 볼 때 | 브라우저 조회 화면, 스크립트 한 번 실행 |
| **자동** | 정해진 시각마다 같은 목록을 CSV로 남길 때 | 스크립트 + Windows 작업 스케줄러 |

조회만 한다. 가격을 바꾸거나 장바구니에 담거나 주문하는 기능은 없다.

## 1. 시작 전 확인

### 1-1. 등록된 위치에서만 열린다

사무실과 집 인터넷(공인 IP)만 등록돼 있다. 휴대폰 데이터, 카페 와이파이, 다른 장소에서는 열리지 않는다.

확인: 브라우저에서 아래 주소를 연다.

```
https://dev.popcornai.co.kr/api/mall-ai-gateway/lookup
```

| 화면 | 뜻 |
|---|---|
| 「윈윈 가격 조회」 화면이 열림 | 사용 가능 |
| 「허용되지 않은 접속 위치」 | 이 장소는 등록돼 있지 않다. 1-2를 본다 |
| 「Not Found」 | 조회 기능이 꺼져 있다. 관리자에게 문의한다 |

### 1-2. 새 장소를 등록하려면

1. 그 장소의 PC에서 구글에 `내 IP`를 검색한다.
2. 나온 숫자(예: `121.xxx.xxx.xxx`)를 관리자에게 보낸다.
3. 관리자가 등록하면 바로 열린다.

가정용 인터넷 IP는 공유기를 껐다 켜거나 통신사 사정으로 바뀔 수 있다. 잘 되던 집에서 갑자기 막히면 IP가 바뀐 것이다.

## 2. 수동 조회

### 2-1. 조회 화면 (가장 쉬운 방법)

1. 브라우저(크롬, 엣지)에서 `https://dev.popcornai.co.kr/api/mall-ai-gateway/lookup`을 연다. 즐겨찾기에 넣어 둔다.
2. **상품번호** 칸에 번호를 넣는다.
   - 쉼표, 공백, 줄바꿈 어느 것으로 구분해도 된다.
   - 엑셀에서 상품번호 열을 복사해 그대로 붙여 넣어도 된다.
   - 한 번에 50개까지.
3. **조회**를 누른다. 키보드로는 `Ctrl+Enter`.
4. 아래 표에 결과가 나온다. 표가 넓으면 가로로 밀어서 본다.

| 버튼 | 하는 일 |
|---|---|
| 조회 | 입력한 번호를 윈윈에 묻는다 |
| 초기화 | 입력과 결과를 지운다 |
| 표 복사 | 결과 표를 복사한다. 엑셀 빈 칸을 누르고 `Ctrl+V`로 붙여 넣는다 |

### 2-2. 자주 보는 묶음을 즐겨찾기로

주소 뒤에 `?pd_no=번호,번호`를 붙이면 열자마자 조회한다.

```
https://dev.popcornai.co.kr/api/mall-ai-gateway/lookup?pd_no=124401,124407,124409
```

이 주소를 즐겨찾기에 「그래픽카드 묶음」처럼 이름 붙여 저장하면 클릭 한 번으로 본다.

### 2-3. 스크립트로 한 번 CSV 만들기

번호가 50개를 넘거나 파일로 남기고 싶을 때 쓴다. 준비는 3-1을 먼저 한다.

1. 시작 메뉴에서 `PowerShell`을 연다.
2. 아래를 붙여 넣고 Enter. 번호만 바꾼다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\윈윈가격\mall_price_export.ps1" -Codes "124401,124407,124409" -OutDir "C:\윈윈가격"
```

3. `완료: 요청 3건 ...`이 나오면 `C:\윈윈가격` 폴더에 `윈윈가격_날짜_시각.csv`가 생긴다. 더블클릭하면 엑셀로 열린다.

목록 파일로 돌리려면 `-Codes "..."` 대신 `-InputFile "C:\윈윈가격\상품목록.txt"`를 쓴다. 번호 수 제한이 없다. 50개씩 나눠 묻고 묶음 사이에 1.2초 쉰다.

## 3. 자동 조회 (정해진 시각마다 CSV 저장)

### 3-1. 준비 (한 번만)

1. `C:\윈윈가격` 폴더를 만든다.
2. 관리자에게 받은 `mall_price_export.ps1`을 이 폴더에 넣는다.
3. 같은 폴더에 메모장으로 `상품목록.txt`를 만든다. 한 줄에 번호 하나씩 쓴다. `#`으로 시작하는 줄은 메모로 무시된다.

```
# 그래픽카드
124407
# 쿨러
124401
124409
```

4. 메모장에서 저장할 때 **인코딩을 UTF-8**로 고른다. (한글 메모를 쓰지 않으면 상관없다.)

### 3-2. 시험 실행

PowerShell에서 한 번 돌려 본다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "C:\윈윈가격\mall_price_export.ps1" -InputFile "C:\윈윈가격\상품목록.txt" -OutDir "C:\윈윈가격"
```

`완료:`가 나오고 CSV가 생기면 다음 단계로 간다. `실패:`가 나오면 5장 문제 해결을 본다.

### 3-3. 작업 스케줄러에 등록

**방법 A: 명령 한 줄 (권장)**

PowerShell에서 아래를 실행한다. 매일 오전 9시에 돈다.

```powershell
schtasks /Create /TN "윈윈가격조회" /SC DAILY /ST 09:00 /TR "powershell -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\윈윈가격\mall_price_export.ps1 -InputFile C:\윈윈가격\상품목록.txt -OutDir C:\윈윈가격"
```

다른 주기로 돌리려면 `/SC DAILY /ST 09:00` 부분만 바꾼다.

| 원하는 주기 | 바꿀 부분 |
|---|---|
| 매일 오전 9시 | `/SC DAILY /ST 09:00` |
| 평일 오전 9시 | `/SC WEEKLY /D MON,TUE,WED,THU,FRI /ST 09:00` |
| 1시간마다 (9시부터) | `/SC HOURLY /MO 1 /ST 09:00` |

**주기는 10분보다 짧게 잡지 않는다.** 윈윈 서버에 부담이 가고 같은 IP로 다른 사람의 조회와 겹친다.

**방법 B: 화면으로 등록**

1. 시작 메뉴 → `작업 스케줄러`를 연다.
2. 오른쪽 `기본 작업 만들기` → 이름 `윈윈가격조회` → 다음.
3. 트리거: `매일` → 시각 `09:00` → 다음.
4. 동작: `프로그램 시작` → 다음.
5. 프로그램: `powershell`
6. 인수 추가:
   ```
   -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\윈윈가격\mall_price_export.ps1 -InputFile C:\윈윈가격\상품목록.txt -OutDir C:\윈윈가격
   ```
7. 마침.

### 3-4. 잘 돌았는지 확인

- `C:\윈윈가격` 폴더에 시각이 붙은 CSV가 새로 생긴다.
- `C:\윈윈가격\mall_price_export.log`에 한 줄씩 기록된다. `완료:`면 정상, `실패:`면 이유가 함께 적힌다.
- 지금 바로 한 번 돌려 보려면: `schtasks /Run /TN "윈윈가격조회"`

PC가 꺼져 있거나 사무실 밖(등록 안 된 위치)이면 그 회차는 `실패:`로 남고 건너뛴다. 다음 회차에 다시 돈다.

### 3-5. 목록 바꾸기, 멈추기, 지우기

| 하고 싶은 것 | 방법 |
|---|---|
| 조회할 번호 바꾸기 | `상품목록.txt`만 고친다. 등록은 그대로 둔다 |
| 잠시 멈추기 | `schtasks /Change /TN "윈윈가격조회" /DISABLE` |
| 다시 켜기 | `schtasks /Change /TN "윈윈가격조회" /ENABLE` |
| 완전히 지우기 | `schtasks /Delete /TN "윈윈가격조회" /F` |

CSV는 자동으로 지워지지 않는다. 쌓이면 오래된 파일을 직접 정리한다.

| 판매가−원가 | 판매가에서 원가를 뺀 값(조회 화면만) |

- 값은 조회한 그 순간의 윈윈 값이다. 저장해 두지 않으므로 같은 번호도 다시 조회하면 바뀔 수 있다.

## 5. 문제 해결

| 증상 | 원인 | 조치 |
|---|---|---|
| 「허용되지 않은 접속 위치」, 로그 `허용되지 않은 접속 위치` | 등록 안 된 장소, 또는 IP가 바뀜 | 1-2대로 IP를 관리자에게 보낸다 |
| 「조회 기능이 꺼져 있습니다」, 로그 `조회 기능이 꺼져 있음` | 관리자가 기능을 껐다 | 관리자에게 문의 |
| 「다른 조회가 진행 중입니다」 | 다른 사람이 같은 순간에 조회 중 | 몇 초 뒤 다시 조회. 스크립트는 2초 간격으로 3번까지 알아서 다시 묻는다 |
| 「윈윈 API가 서버 IP를 거부했습니다」, 로그 `윈윈 API 실패` | 윈윈 쪽에서 우리 서버를 막았다 | 관리자에게 바로 알린다 |
| 「윈윈 API 응답 시간이 초과」 | 윈윈 서버가 느리다 | 잠시 뒤 다시 |
| 로그 `서버에 연결하지 못함` | 인터넷 끊김 | 인터넷 연결 확인 |
| 로그 `숫자가 아닌 상품번호` | 목록 파일에 글자가 섞임 | `상품목록.txt`에서 그 줄을 고치거나 앞에 `#`을 붙인다 |
| PowerShell에 빨간 글씨로 `이 시스템에서 스크립트를 실행할 수 없으므로` | 실행 정책 | 명령에 `-ExecutionPolicy Bypass`가 빠졌다. 매뉴얼의 명령을 그대로 쓴다 |
| CSV를 열었더니 한글이 깨짐 | 엑셀이 다른 인코딩으로 열었다 | 엑셀 → `데이터` → `텍스트/CSV에서` → 파일 원본 `65001: 유니코드(UTF-8)` |
| 작업 스케줄러에 등록했는데 파일이 안 생김 | 그 시각에 PC가 꺼져 있었거나 사무실 밖이었다 | `mall_price_export.log`를 본다. 로그도 없으면 등록 명령의 경로를 다시 확인한다 |

## 6. 꼭 지킬 것

- **원가가 들어 있다.** 조회 화면 캡처, CSV 파일을 고객, 외부 메신저, 공개 게시판에 보내지 않는다. (낡음 2026-11-17: 원가는 더 나오지 않는다. 판매 상태가 실제와 다를 수 있으므로 외부에 보내지 않는 규칙은 그대로 둔다.)
- 자동 조회 주기는 **10분 이상**으로 둔다.
- 서버에는 조회 건수와 오류만 기록되고, 상품명과 가격은 남지 않는다. 기록이 필요하면 CSV를 보관한다.
