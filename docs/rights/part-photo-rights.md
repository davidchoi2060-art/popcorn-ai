# 부품 사진 사용 근거 (v1)

이 문서는 부품 설명 옆에 표시하는 **등록 부품 사진**의 사용 근거 원장이다.
`POPCORN_PART_PHOTO_RIGHTS_REFERENCE` 값은 이 파일의 경로·버전·내용 해시로 만든다.
부품 사진 승인 기록(`part_photo_approval_events`)은 모두 이 값을 함께 저장한다.

## 1. 대상

| 항목 | 값 |
|---|---|
| 저장소 | 비공개 버킷 `popcorn-ai-product-media-045e861b` |
| 경로 | `products/{상품코드}/{원본 SHA256 앞 16자}/` |
| 파일 | `original.*` · `detail.png` · `thumb.webp` (상품당 3개) |
| 규모 | 부품 201종 · 파일 603개 (2026-09-28 최종 검사 기준) |
| DB 연결 | `product_explanations.content.image_asset` |
| 승인 대상 파일 | `detail.png` (`part_photo_approval` 이 SHA256 을 대조한다) |

완성 PC 대표 이미지(`pc-configurations/…/representative.png`)는 이 문서의 대상이 아니다.
그 이미지는 AI 조립 예시다. 기존 원본을 들여온 것은 `pc_media_jobs.import_provenance` 에, 새로 생성한 것은 같은 표의 `snapshot`·`asset` 에 따로 기록된다.

## 2. 자료의 출처

- 원본은 판매처(팝콘PC 몰) 상품 상세에 등록된 제품별 대표 이미지(`image_url`)다.
- 원본 픽셀을 유지하고 외곽 여백만 재단했다. 박스·글자·반사·그림자를 새로 그리거나 지우지 않았다.
- 원본 URL 은 고객에게 공개하지 않는다. 고객 화면은 자체 저장소의 상세·썸네일만 받는다.
- 다나와 등 다른 사이트의 이미지는 쓰지 않는다(결정 로그 A-106 과 같은 원칙).

## 3. 권리 보유와 사용 판단

- 이미지는 판매처가 해당 상품을 팔기 위해 상품 상세에 게시한 자료다.
- 제조사·공급처와의 개별 이용 허락서는 이 저장소에 없다. 법률 검토 기록도 없다.
- 그 위에서 **같은 상품을 판매하기 위한 부품 사진으로 사용한다**는 것이 사업자 판단이다.
  판단 기록은 4절이다.

## 4. 승인 기록

| 일시 | 승인 내용 | 기록 위치 |
|---|---|---|
| 2026-09-28 | 판매처에 등록된 제품별 사양·이미지를 사용 가능한 자료로 인정 | `HANDOFF.md` §「2026-09-28 사용자 표시·자료 기준 변경」 |
| 2026-09-28 | 원본 픽셀을 유지한 자동 여백 재단과 자체 저장소 이관 승인 | `HANDOFF.md` §「2026-09-28 제품 이미지 저장소 적용」 |
| 2026-10-09 18:40 KST | 중헌 원문: 「근거는 모두 이전에 다 승인했어.」 | 프로젝트 채팅 |

확인된 것은 위 원문뿐이다. 이 원문이 위 두 승인(2026-09-28)을 가리키고, 그 승인을
부품 사진 승인 원장의 근거로 써도 된다는 뜻이라는 것은 **작성자의 해석**이다.
해석의 범위는 1절의 대상(201종·603파일)으로 한정하며, 새 이미지를 추가로 허락한 것으로 읽지 않는다.

## 5. 사용 범위

- 해당 부품의 설명 옆 구성품 사진으로만 쓴다.
- 완성 PC 외형이나 실제 출고 외형을 뜻하지 않는다.
- 이 문서는 사진 사용 근거일 뿐이다. 부품 설명 승인·구성 발행 승인·판매 허가를 대신하지 않는다.

## 6. 참조값과 변경 절차

    POPCORN_PART_PHOTO_RIGHTS_REFERENCE=workroom:docs/rights/part-photo-rights.md@v1:<이 파일의 sha256>

- 해시는 main 에 병합된 파일로 계산한다: `sha256sum docs/rights/part-photo-rights.md`
- 문서를 고치면 제목의 버전을 올리고 참조값을 새로 만든다.
- 참조값이 바뀌면 기존 부품 사진 승인은 모두 「근거 변경」으로 바뀐다. 새 참조값으로 다시 승인해야 한다.
